# 网文对话模式与技法参考

本文件是 dialogue-diagnostics 的核心参考。包含网文特有对话模式的写法指南、反模式库、古风用语指南、对话标签用法。

---

## 一、网文特有对话模式

以下模式本身不是反模式——用好了是爽点和节奏利器，用差了变成套路和注水。

### 1. 装逼打脸对话

网文最经典的对话模式。核心结构：

1. **反派/配角嘲讽主角**（建立反差）——"就凭你一个废物，也敢觊觎这株天材地宝？"
2. **主角淡然回应或沉默**（蓄势）——主角只是淡淡地看了他一眼。
3. **实力展示后的一句话反击**（爽点释放）——"废物？你连废物都不如。"

**写好的关键：**

- 反派嘲讽要精炼有力，一两句话建立蔑视感，不要长篇大论（读者急着看打脸）
- 主角反击台词要有记忆点——最好的反击是简短、冷酷、带画面感的一句话
- 围观群众的反应用来放大爽感，但不要每个人都说一遍"天哪他好强"
- 避免每次打脸都是同一个模式，要在结构上做变体

**常见问题：**

- 反派嘲讽太长太啰嗦（三句话内建立冲突）
- 主角反击台词太平淡（缺乏金句感）
- 每次打脸模式完全一样（审美疲劳）
- 围观群众反应变成复读机

**结构变体：**

- 主角沉默到底不说话，用行动打脸
- 提前反击打乱节奏
- 让配角替主角说话
- 反派自以为赢了在嘲讽，主角已经走了

### 2. 师徒/传承对话

用于修仙/玄幻中的知识传递场景。最容易滑入 D3 设定百科型（信息倾泻）。

**好的师徒对话特征：**

- 师父说半截话，学生自己悟
- 师父用隐喻和故事讲道理，而非直给
- 师徒之间有性格碰撞（严师出高徒 / 亦师亦友 / 不靠谱师父）
- 传承的不只是知识，更是价值观和处世之道

**避免：**

- 老师连说十句设定
- "道可道非常道"式的故弄玄虚
- 学生只会点头和"是"

**更好的方式：** "我说一百遍不如你自己试一次"，然后切入修炼/战斗场景。

### 3. 系统/面板对话

系统文特有的对话形态。

**系统提示节奏范例：**

```
【叮！检测到宿主遭受致命攻击。】
【已触发被动技能：不死鸟之躯。】
【剩余复活次数：2】

"……就不能提前告诉我有这技能吗？"

【系统建议宿主下次注意躲避。】
```

**要点：**

- 系统提示用方括号或特殊格式与正常对话区分
- 保持简洁，信息密度高
- 主角的回应是吐槽点和人格体现
- 系统越一本正经，主角的吐槽越好笑
- 避免系统面板信息量过大——只展示关键信息，其余折叠或推迟

### 4. 宗门/势力对话

门派、家族、组织中的对话，核心在于**身份等级决定语言**。

**身份等级语言差异：**

| 身份 | 语言特征 | 示例 |
|:---|:---|:---|
| 宗主/族长 | 简短、一锤定音 | "准了。" "不必再议。" |
| 长老 | 稳重、引经据典 | "按祖训，此事当如此处置。" |
| 核心弟子 | 自信但有分寸 | "师叔明鉴，弟子有一事禀报。" |
| 外门弟子 | 拘谨、卑微 | "回、回禀长老，弟子不敢隐瞒……" |
| 散修 | 直接、粗犷 | "你们宗门的规矩，管不到我头上。" |

**要点：**

- 宗门会议是权力博弈的舞台——每个发言者都有立场和利益
- 弟子之间的明争暗斗通过对话展现——表面师兄弟和气，暗地里在争资源争地位
- 不同辈分的称谓和语气必须有区分

## 二、反模式库

### 1. 信息倾泻

**模式：** "如你所知，这片大陆叫做苍穹大陆，分为东南西北四大域……"

**问题：** 角色为了读者的利益解释双方共知的信息。

**修复：** 在信息中找到冲突或在场景中让角色发现它。

### 2. 双胞胎

**模式：** 老爷爷、小萝莉、中年大叔说话方式完全一样。

**问题：** 没有标签就无法区分声音。

**修复：** 为每个角色建立语言模式档案；赋予独特的言语 DNA。

### 3. 庭审记录员

**模式：** "呃，嗨。""哦，嘿，是的，那个……""对，对。"

**问题：** 太真实但戏剧性已死——小说对话是压缩的现实。

**修复：** 删减到有意义的部分；闲聊只在揭示角色时使用。

### 4. 情绪旁白者

**模式：** "他震惊道""她恐惧道""他不敢置信道"

**问题：** 标签在做对话的工作；告知而非展示。

**修复：** 让言语和动作承载情感。"滚！"不需要写成"他愤怒地大喊道"。

### 5. 哲学家

**模式：** 角色清楚地表述主题、教训或潜台词。

**问题：** 剥夺了读者的信任；说教感。

**修复：** 信任读者能从行为和暗示中推断含义。

### 6. 网球赛

**模式：** 完美交替、大小均匀的回应，没有打断或权力差异。

**问题：** 不自然地平衡；没有人主导或退让。

**修复：** 让一个角色主导，另一个打断，第三个保持沉默。

### 7. 复读机围观（网文特有）

**模式：** 每次主角展示实力后，围观群众轮流震惊——"不可能！""我的天！""这怎么回事？！"

**问题：** 第一次有效，第三次开始变成注水。

**修复：** 限制围观反应数量；用一两个有代表性的角色反应代替群像；让围观者的反应推进情节（例如有人起了杀心）。

## 三、古风对话用语指南（仙侠/历史类）

### 基本原则

- 不必追求真正的文言文，追求的是"古风感"
- 核心是去掉现代口语痕迹，而非堆砌古词
- 保持可读性——读者不需要查字典

### 常用替换

| 现代说法 | 古风替代 | 注意 |
|:---|:---|:---|
| 你 | 你/阁下/道友/前辈 | 根据关系选择称谓 |
| 我 | 我/在下/本座/贫道 | 根据身份选择自称 |
| 是的 | 正是/然也/不错 | 简短即可 |
| 不行 | 万万不可/不妥/此事不宜 | 根据语气选择 |
| 为什么 | 何以至此/这是为何/何故 | 避免总用同一个 |
| 怎么办 | 当如何是好/该作何处置 | 不要过度文绉绉 |
| 谢谢 | 多谢/承蒙厚爱/大恩不言谢 | 视关系深浅而定 |

### 避免的假古风

- 乱用"之乎者也"（这些是语气词，不是装饰品）
- 现代概念硬套古风壳（"本座觉得你的战斗力指数不太OK"）
- 所有人说话都一样文绉绉（粗人就该说粗话，小孩就该说童言）

### 不同身份的古风语言层次

- **仙人/大能：** 言简意赅，不屑解释。"去。""留。""尚可。"
- **世家子弟：** 礼节到位，暗藏锋芒。"兄台说笑了，不过此言若传出去，恐怕不太好听。"
- **江湖粗人：** 直来直去，偶带粗口。"少废话，打不打？"
- **书生/谋士：** 引经据典，说话绕弯。"昔年某某曾言……不知阁下以为然否？"
- **小人物/凡人：** 大白话为主，偶尔用错雅词闹笑话。"那个、那个大仙，小的有眼不识泰山……"

## 四、中文对话标签规范

### "说/道"字的替代——使用与克制

中文拥有极丰富的对话标签词库，是优势，也容易过度使用：

| 类型 | 常用标签 | 使用场景 |
|:---|:---|:---|
| 中性 | 说道、道、说 | 日常对话，高频使用 |
| 语气 | 冷哼道、嗤笑道、沉声道、淡淡道 | 需要传递语气时偶尔使用 |
| 音量 | 低喝道、厉声道、轻声道、大笑道 | 声音状态确实重要时使用 |
| 动作融合 | 摇头道、拱手道、抬眼道 | 需要同时传递动作和语言时使用 |

### 引号使用

- 网文标准格式：中文双引号 "" 包裹对话
- 内心独白：单引号 '' 或斜体
- 系统提示：方括号 【】
- 每句对话独立成段

## 五、特殊对话场景快查

| 场景 | 核心要点 |
|:---|:---|
| 争吵 | 答非所问；通过重复升级；旧怨突然浮现；说出无法收回的话 |
| 对峙 | 权力动态明确；礼貌之下的威胁；出现赢家和输家 |
| 试探/诱惑 | 说的是一回事意思是另一回事；逐渐揭示；没说的最重要 |
| 说谎 | 角色相信自己说的；与性格一致地撒谎；其他角色可能察觉也可能没有 |

## 六、核心洞察

> 对话是压缩的现实。它听起来自然但并非自然——它是精心构建的，目的是在服务故事的同时让人感觉自发。

> 大多数对话问题都是潜台词问题。给每个角色一个隐藏目的。让他们想要无法直接开口要求的东西。说出的和意味的之间的差距，就是戏剧存在的地方。

> 网文额外洞察：**爽感来自反差和节奏，不来自字数。** 打脸对话中，反派的嘲讽越精炼，主角的反击越简短，爽感反而越强。信息倾泻是网文对话的头号杀手。
