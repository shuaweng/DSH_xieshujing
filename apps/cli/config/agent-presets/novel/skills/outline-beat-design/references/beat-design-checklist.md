# Beat Design Checklist

## 一、先钉住上层

### 书级

- 这本书的大问题是什么
- 核心卖点是什么
- 读者长期期待什么
- 如果有对标作品：提取结构要素（总卷数、卷主题、节奏密度、换地图逻辑）

### 卷级（7 项必填）

1. 主角本卷目标
2. 本卷最大阻力
3. 本卷核心兑现
4. 卷末变化（地位/关系/认知）
5. 下一卷入口
6. 本卷字数预估与章数范围
7. 本卷爽点节奏规划

## 二、章级固定七问

每章先问：

1. 本章目标
2. 本章阻力
3. 本章关键变化
4. 本章信息释放
5. 章末入口
6. 伏笔操作：埋入 / 推进 / 收回
7. 爽点标记：爽点章 / 铺垫章 / 转折章

## 三、beat 链

### 默认模板

1. 起手
2. 压力抬升
3. 应对
4. 结果
5. 新不稳定

### 替代模板

- 目标 -> 冲突 -> 结果（场景）
- 反应 -> 困境 -> 决定（续篇）

### 场景爆炸要求

每章必须拆到最细的场景粒度，每个场景 beat 包含：

- 发生什么（一句话）
- 写法指导（情绪基调、节奏要求）
- 与章目标的关系

## 四、爽点分布检查

| 级别 | 频率 | 检查项 |
|:---|:---|:---|
| 黄金三章 | 前三章至少 1 个强爽点 | 是否有？够不够强？ |
| 小爽 | 每 3-5 章 | 是否均匀分布？有无真空？ |
| 大爽 | 每卷末 | 是否与卷目标兑现对齐？ |
| 超爽 | 全书 2-3 个 | 是否安排在关键节点？ |

**爽感真空**：连续 5 章以上没有任何爽点释放 → 必须标记

## 五、伏笔平衡检查

| 类型 | 生命周期 | 频率 |
|:---|:---|:---|
| 短线 | 10-20 章内收回 | 每卷 2-3 条 |
| 中线 | 一卷内收回 | 每卷 1-2 条 |
| 长线 | 跨卷收回 | 全书 2-3 条 |

**伏笔异常**：
- 只埋不收 → 读者遗忘
- 收回密集 → 感觉赶工
- 从不埋新线 → 后继无力

## 六、常见故障

### 1. 只有事件，没有功能

- 看起来发生了很多事
- 但这一章拿掉也不影响卷目标

### 2. 只有推进，没有兑现

- 连续多章都在预热
- 读者没有可感知回报（爽感真空）

### 3. 只有兑现，没有升级

- 每章都像在收钱
- 但风险和局面不再抬高

### 4. 支线拖散主线

- 支线有趣，但没服务卷目标
- 主角的主问题被冲淡

### 5. 章末入口外生

- 不是当前变化长出来的
- 而是作者额外拉一句"后面会更精彩"

### 6. 大纲像设定集

- 只罗列世界观、体系、人物
- 没有起承转合与卷推进
- 解法：找出核心冲突线，倒推事件序列

### 7. 模板化重复

- 每卷/每章都是同一模式
- 冲突→解决→升级的无限循环
- 解法：变换冲突类型、arena、解法机制

## 七、俗套速查

| 俗套 | 表现 | 超越方向 |
|:---|:---|:---|
| 捡传承 | 山洞/老爷爷/神秘空间 | 传承有代价、附带诅咒、传承者有自己的目的 |
| 反派送人头 | BOSS 无脑上门被打脸 | 反派有合理动机、打脸需要策略不是碾压 |
| 退婚流堆砌 | 退婚+废修为+戒指老爷爷 | 保留情绪内核（逆袭），换全新包装 |
| 天才女主倒贴 | 万年天才无条件倒贴 | 女角色有独立动机，吸引需要理由 |
| 工具人配角 | 只为衬托主角 | 配角有自己的目标和声音 |
| 修炼随意 | 剧情需要就突破 | 突破有前置条件和代价 |
| 重复打脸 | "你不知道他是谁" | 变换打脸机制、升级打脸对象层级 |

## 八、优先修法

1. 先重写卷目标（7 项必填）
2. 再重排分章职责（7 问检查）
3. 再检查爽点分布和伏笔平衡
4. 再做俗套扫描
5. 最后才细拆 beat（场景爆炸）
