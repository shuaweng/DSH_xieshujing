# 反馈记录实战示例

本文件为 skill-evolution 提供实操参考，帮助 agent 准确提取和分类反馈信号。

---

## 一、信号类型判定指南

### reject（拒绝建议）

用户完全不采纳 skill 产出的某条建议。

**典型用户表述**：
- "这条不用改"
- "这个建议不对，我是故意这样写的"
- "别标这个，短句是我的风格"
- "这不是 AI 味，是角色本来就这样说话"

**记录要点**：精确记录用户拒绝的是哪条规则/哪个检查项。

### modify（接受但大幅修改）

用户采纳了建议的方向，但产出与 AI 给的版本差异很大。

**典型信号**：
- AI 给了改写版本，用户只保留了思路但重新写了
- 用户说"方向对但写法不行"
- 对比 AI 产出和最终版本，改动超过 50%

**记录要点**：记录 AI 给了什么、用户最终改成了什么，差异在哪。

### prefer（用户主动表达偏好）

用户主动说出写作偏好，不一定是对某次具体产出的反馈。

**典型用户表述**：
- "我写对话喜欢用短句"
- "内心独白我习惯用碎句+省略号"
- "我不喜欢用'不禁'这个词"
- "打斗场景我偏好快节奏切镜头"

**记录要点**：原封不动记录用户的偏好表述。

### complain（抱怨/不满）

用户对 skill 整体表现或某类输出表示不满。

**典型用户表述**：
- "这个 skill 每次都太啰嗦"
- "建议太多了，重要的反而看不到"
- "格式太复杂了"
- "老是建议我加心理描写，烦了"

**记录要点**：记录不满的模式，而非单次内容。

### praise（表扬）

用户对 skill 产出表示满意，同样重要——知道什么不该改。

**典型用户表述**：
- "这次改得好"
- "这个诊断很准"
- "节奏分析说到点子上了"
- "就要这种风格"

**记录要点**：记录用户满意的具体方面。

## 二、回顾阶段的模式识别示例

### 示例 A：一贯拒绝模式

```
反馈 #3: reject | style-audit | "短句连续不是 AI 味，是节奏"
反馈 #7: reject | style-audit | "又标了短句，我说过这是风格"
反馈 #12: reject | style-audit | "P3 短促堆叠不适用于打斗场景"
```

→ 稳定模式：用户的短句连续是刻意风格选择，style-audit 的 P3 检查在打斗/紧张场景中应排除。

→ 建议进化：在 style-audit/SKILL.md 的"什么时候不要误判成 AI 味"中新增规则。

### 示例 B：一贯偏好模式

```
反馈 #2: prefer | chapter-execution | "内心独白用碎句+省略号"
反馈 #5: modify | chapter-execution | 把完整心理描写改成碎句
反馈 #9: prefer | rewrite-to-style | "心理活动要短，要碎"
```

→ 稳定模式：用户的心理描写风格偏好碎句化。

→ 建议进化：在 STYLE.md 或 chapter-execution 的相关参考中补充该偏好。

### 示例 C：反复修改模式

```
反馈 #4: modify | dialogue-diagnostics | 对话建议太书面，用户全改成口语
反馈 #8: modify | dialogue-diagnostics | 示范对话太正式，用户加了语气词
反馈 #11: modify | rewrite-to-style | 对话改写后语气不对，用户重写
```

→ 稳定模式：用户的对话风格比 AI 默认更口语化。

→ 建议进化：在 dialogue-diagnostics/references/ 中调整示范对话的口语度。

## 三、进化修改的标注格式

在 skill 文件中插入进化内容时，用 HTML 注释标注来源：

```markdown
<!-- evolved: 2026-04-20, 基于反馈 #3, #7, #12 -->
- 打斗场景中的短句连续（≤4字 × 3句以上）不标记为 P3，属于节奏控制手法
<!-- /evolved -->
```

这样做的好处：
1. 未来回顾时知道每条规则的来源
2. 回滚时可以精确定位
3. 不影响 skill 的正常阅读

## 四、preferences.md 的维护格式

```markdown
# 用户写作偏好

> 本文件由 skill-evolution 自动维护，记录已确认的稳定偏好。
> 各 skill 执行时应参考本文件调整输出。

## 风格偏好

- 心理描写偏好碎句化，避免完整长句（来源：反馈 #2, #5, #9）
- 对话偏口语，允许语气词和不完整句（来源：反馈 #4, #8, #11）

## 检查豁免

- style-audit P3（短促堆叠）在打斗/紧张场景中豁免（来源：反馈 #3, #7, #12）

## 格式偏好

- （待积累）

## 内容偏好

- （待积累）
```
