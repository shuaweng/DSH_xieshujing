# Conflict And Propulsion

这份参考用于解决“为什么这一场不紧、不顶、不想往下看”。

## 一、核心原则

### 1. 欲望对冲

冲突不是主角撞上静态障碍，而是：

- 主角想要什么
- 阻碍方或环境按自己的逻辑推进什么

两边在同一场景里撞上，才有真正的张力。

### 2. 冲突必须带来变化

一场有效冲突结束后，至少要动一项：

- 资源
- 地位
- 认知
- 关系
- 心态底线
- 风险级别

没有变化的冲突，通常只是空转。

## 二、压力四象限

### 1. 绝境区

- 构成：硬性压力 + 恒定环境
- 读感：不得不跑
- 常见场景：追杀、生存危机、倒计时、天灾、封锁

### 2. 两难区

- 构成：软性压力 + 恒定环境
- 读感：不得不选
- 常见场景：道德代价、规则代价、救谁弃谁

### 3. 对抗区

- 构成：硬性压力 + 敌对动机
- 读感：不得不打
- 常见场景：竞争、争夺、阻击、试探、反扑

### 4. 迷雾区

- 构成：未知源头 + 探索竞争
- 读感：不得不猜
- 常见场景：调查、试错、异常事件、未知规则

## 三、怎么选压力

- 一场戏优先只抓 1 种主压力
- 最多叠 2 种
- 不要每次都只会“打起来”

常见有效组合：

- `对抗 + 绝境`
  - 既有人拦，又没时间
- `两难 + 对抗`
  - 既得选，又有人逼
- `迷雾 + 对抗`
  - 不知道真相，但敌人已经动手

## 四、主角锚点

一定要问：

- 他为什么不能退？

常见锚点有三类：

- 生存锚点
- 身份 / 价值观锚点
- 情感保护锚点

没有锚点，冲突就只剩“作者安排主角上”。

## 五、推进链模板

默认先写成 5 格：

1. 主角当前目标
2. 阻碍方或环境压力
3. 主角应对
4. 本轮结果
5. 新的不稳定

最后一格必须回答：

- 为什么读者会想看下一步？

如果回答不了，通常有三个原因：

- 结果太圆满
- 结果虽激烈，但没有改变局面
- 结果刚出来，就被解释完了

## 六、补充：场景-续篇节拍

单个场景要想既顶又不乱，优先按两段来想：

### 1. 场景

`目标 -> 冲突 -> 灾难`

- 目标：
  - 视角角色这一场具体要什么
- 冲突：
  - 阻碍必须逐步升级，不能一直停在同一压力位
- 灾难：
  - 这一场最好不要以干净的“是”结束

更推荐的结果是：

- `是，但是……`
- `不，而且……`
- `不`

### 2. 续篇

`反应 -> 困境 -> 决定`

- 反应：
  - 角色先消化刚发生的事
- 困境：
  - 上一个结果关掉了哪些路、逼出了哪些难选项
- 决定：
  - 角色定下下一步，这会变成下一个场景的目标

### 3. 常见故障

- 只有场景，没有续篇：
  - 一直打、一直冲，但读者没有消化时间
- 只有续篇，没有场景：
  - 一直想、一直分析，但没有真正往前推
- 灾难太干净：
  - 明明打完了，却没留下新的麻烦

## 七、卷内推进与爽点口径

从章到卷，都要问：

- 这一章推进了什么？
- 这一章有没有一个可感知的变化？
- 这一章的爽点是：
  - 微爽点
  - 小爽点
  - 中爽点
  - 还是纯铺垫章
- 如果是铺垫章，结尾有没有把下一章的读者理由接上？

不要让连续多章都处于：

- 没有明显变化
- 没有爽点
- 没有新风险
- 没有新决定

否则读者会感觉在原地空转。

## 八、角色成长不要写成“献祭流”

更适合中文网文的代价，往往不是悲剧性牺牲，而是：

- 心态更狠
- 处世更警惕
- 判断更偏执
- 底线被改写

也就是：冲突过后，人变了。

## 九、冲突递进与角色成长阶段

冲突设计必须伴随角色的成长轨迹：

- **初期**：基于"表层欲望"（求生、求财、求安全）。压力来源以绝境区和对抗区为主。
- **中期**：面临"身份拷问"（我到底站哪边、我的底线在哪）。压力开始叠加两难区。
- **后期**：面临"幽灵驱动"的终极拷问（价值观的两难选择、付出与坚持的意义）。四个象限交织。
- **代价逻辑**：真正的代价是主角**心态与为人处世的变化**——从天真到警惕，从善良到狠辣，从信任到设防。

## 十、冲突设计工作流（4 步法）

当需要为一个场景或章节设计冲突时，按以下步骤执行：

### 1. 确立双方欲望（欲望对冲分析）

- 明确主角的当前欲望是什么
- 明确反派或环境的阻碍逻辑是什么
- 输出："主角的诉求 vs 阻碍方的逻辑"

两边在同一场景里撞上，才有真正的张力。如果阻碍方只是"静态的墙"，那不是冲突，是通关。

### 2. 选择压力象限

- 从四大象限中选择 1-2 个作为核心压力源（参见上文"压力四象限"）
- 说明该场景下的具体压力表现
- 尝试叠加两个象限以提升张力

### 3. 设置主角锚点

- 主角为什么不能退缩？
- 三类锚点：生存锚点 / 身份价值观锚点 / 情感保护锚点
- 没有锚点的冲突只剩"作者安排主角上"

### 4. 推演冲突结果

- 主角付出了什么"成长代价"？
- 获得了什么实质性变化？
- 输出分为："付出的代价（心态/认知变化）"和"获得的实质变化（资源/地位/情报）"

## 十一、冲突检验清单

设计完冲突后必须自检：

- [ ] 反派/阻碍方是否有主动推进的欲望和立得住的逻辑？
- [ ] 压力是否足够厚重？（是否考虑了叠加象限？）
- [ ] 主角是否有明确的不能退的锚点？
- [ ] 冲突结束时，是否带来了读者可见的实质性变化？
- [ ] 结果是不是打开了新的不稳定状态？
- [ ] 成长代价是"人变了"，而不是"人残了"？

## 十二、自检清单（综合）

- 阻碍方有没有自己的欲望和逻辑？
- 压力是不是直接顶到主角当前目标上？
- 主角是不是有明确不能退的理由？
- 结果是不是带来了实质变化？
- 这一轮结果有没有打开新的不稳定状态？
- 场景之后有没有最小续篇去消化和导向下一步？
- 连续几章看下来，爽点/变化/新麻烦是不是在递进？
