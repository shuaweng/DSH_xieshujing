# Chapter Wrap Sync Checklist

这份参考用于章节写完后的同步判断。

## 一、必须检查的 5 类变化

1. 角色正式信息是否新增或变化
2. 世界/系统/修行硬规则是否被明确
3. 当前卷纲是否被正文实际推进改写
4. 是否出现了新的候选想法
5. 是否新增或解决了未决问题

## 二、最常见的 6 种该同步情况

### 1. 主角能力边界第一次被明确

应考虑：

- 更新人物设定
- 如涉及硬规则，也更新世界/系统规则

### 2. 某个原本猜测的设定被正文正式坐实

应考虑：

- 从 `candidate` / `open` 提升到 `confirmed`

### 3. 本章把卷纲里的事件提前或延后了

应考虑：

- 更新 `working` 卷纲

### 4. 本章埋了后面必须兑现的新坑

应考虑：

- 写入 `open_questions`

### 5. 本章回收了一个旧伏笔

应考虑：

- 从伏笔追踪中标记为已回收

### 6. 写作过程中冒出了一条好想法，但正文还没正式坐实

应考虑：

- 写入 `idea_backlog`
- 不要误写入 `confirmed`

## 三、最常见的不该同步情况

- 角色一时的误会
- 某个配角的猜测
- 作者还没想定、只是顺手写出来的试探性桥段
- 纯情绪描写，没有带来稳定事实变化

## 四、优先级

如果同步量很大，优先顺序建议是：

1. 正式设定
2. 卷纲
3. 未决问题
4. 脑洞池
5. 伏笔追踪
