# Style Audit Checklist

## 一、AI 味基础约束

### 1. 词汇与句式黑名单

- 反复用单一主语开头，尤其是“他/她感到……”“他知道……”“他明白了……”
- 反复用“一股XX涌上心头”“心里一沉”这类套路化心理描写
- 反复用“他的眼神/表情/语气说明了一切”
- 过度依赖“宛如 / 仿佛 / 犹如 / 似乎”
- 出现“值得注意的是”“不难发现”“总而言之”等说明文习语
- 大量无意义时间戳、倒计时、精确时长
- 破折号、分号被拿来硬造节奏或硬造震撼感

### 2. 句法与节奏

- 句子过于规整，像模板化短句排比
- 长短句没有错落，全文都在一个拍子上
- 书面语、翻译腔明显强于口语化叙述
- 战斗、冲突、推进场景里动作不够干脆
- 段落全都一个长度，像排版器统一切出来的
- 连续多个句子都以“他/她/我 + 动词”开头

### 3. 情感与视角

- 情绪只有标准答案，没有矛盾、停顿、迟疑和别扭感
- 主角总是正确、冷静、理解一切，很少有烦躁、自嘲、犹疑、破防
- 章末用抒情、总结、升华、发散思考收尾

### 4. 对话

- 不同角色说话像同一个人
- 角色反复使用同一类句式或同一个口头表达
- 对话把背景、设定、心理都直白讲穿，没有潜台词
- 台词过于完整、正式、干净，像写说明文而不是人开口
- 角色互相解释彼此已经知道的事，只是为了讲给读者听

## 二、更细粒度的结构 / 文风 / 对话检查项

### 1. humanizer 高风险结构

- 同一段里不停轮换同义称谓：
  - “青年 / 少年 / 天才 / 修士 / 林逸”来回切
- 三段式凑数：
  - 一个描述总爱凑成三项并列
- 否定式排比：
  - “这不仅仅是……更是……”
  - “这不是……而是……”
- 夸大象征意义：
  - 刚发生一件事，旁白马上宣布“这是历史转折点”
- 宣传式描写：
  - 场景像旅游文案、宣传片旁白，而不是故事现场
- 通用积极结尾：
  - 不管前面发生什么，最后都收成“未来仍充满希望”

### 2. prose-style 句法与声音问题

- 白开水文：
  - 只有动作信息，没有画面、温度、声音、触感
- 过度修饰：
  - 一个名词前堆两三个形容词
  - 一段里比喻过多，像在炫技
- 节奏失控：
  - 该快的地方拖长
  - 该停顿的地方一笔带过
- 句式单调：
  - 句长过于一致
  - 段长过于一致
- 声音不一致：
  - 同一章里文风忽然从网文口语跳成抒情散文或说明文
- 视角混乱：
  - 一段里混进多个角色的直接心理

### 3. dialogue 对话诊断项

- 声音同质化：
  - 不看标签分不出是谁在说话
- 生硬对白：
  - 句子太完整，没有片段、打断、回避、答非所问
- 信息倾泻：
  - 角色借聊天讲设定、补背景、替读者总结
- 潜台词不足：
  - 说出来的就是全部意思，关系张力和权力差都不在台词里
- 语境失真：
  - 年龄、身份、修为、出身完全不影响说话方式

## 三、人物真实感检查

### 1. 动机与私心

- 行为只有剧情功能，没有角色自己的小算盘
- 角色只有表面动机，没有内在私欲、恐惧或顾虑
- 爱恨与敌我切换没有动机支撑

### 2. 弱点与瑕疵

- 角色几乎不犯错、不误判、不犹豫
- 高冷者永远高冷，聪明人永远英明，没有破防和失手
- 极端情境下也始终做“最正确”的反应

### 3. 细节与习惯

- 没有可识别的个人细节
- 对不同人态度都一样
- 完全没有主线之外的活人感痕迹

### 4. 思维与成长

- 角色思考过于幼稚或过于扁平
- 成长是一夜顿悟，没有旧习惯反扑
- 现在的行为看不出过去经历留下的痕迹

## 四、简洁写作检查

### 1. 修饰语约束

- 一个名词/动词前堆太多形容词或修饰语
- “A，却带着B”“既……又……”被滥用来堆感受
- “带着某种……”“一丝……”这类空泛修饰过多

### 2. 动作与对话

- 能用具体动作表现，却改成抽象形容
- 对话提示语过长，抢走对白的力度
- 战斗和冲突动作拖泥带水

### 3. 删繁就简

- 一段里没有推进，只是在补修饰、补解释
- 反复说明同一层意思，不相信读者能自己理解
- 明明可以直接写结果，却先绕一圈下定义、做判断、讲意义

## 五、补充高风险表达与逻辑信号

### 1. 语法与句式

- 并列定语和修饰链过长，读感发涩
- 多余逗号太多，句子停顿像被切碎
- 超过 20 字的从句堆叠明显拖住叙述

### 2. 套路化表达

- “脸上带着笑意”“眼神热切”“目光里毫不遮掩”
- “深吸一口气缓缓地”“指节因用力而发白”
- “嘴角勾起一抹/一丝弧度/冷笑/玩味”
- “锐利的 / 深邃的 / 森然的 / 冰冷的 / 难以置信的”
- “像一盆冰水 / 像一记重锤 / 像一根钢针”这类陈词滥调
- “他相信 / 他知道 / 心中一动 / 电光火石之间 / 说时迟那时快”

### 3. 逻辑与视角

- 对话或剧情后紧跟一段“这意味着……”
- 作者比角色更急着下判断、做总结
- 为了显得“像小说”，强塞现代梗而不顾角色语境

## 六、解释腔高风险信号

- 设定一出现就讲原理
- 打斗中途开始上课
- 角色和读者都还没反应，旁白先总结
- 对话里用“如你所知”式信息补课
- 角色只是说话，不顺手推进关系、权力、误判或冲突

## 七、假钩子高风险信号

- “但他们不知道的是……”
- “真正可怕的是……”
- “就在这一夜……”
- “一个新的时代开始了……”
- 用作者旁白强行宣布“接下来很重要”

## 八、信息释放失控信号

- 主角独特路线刚露头就被配角看穿
- 爽点还没兑现，原理先说完了
- 本来应该后置揭示的东西，本章直接讲明
- 配角替读者完成理解，主角失去神秘感和领先感

## 九、网文感不足信号

- 没有明确推进
- 只有气氛，没有变化
- 只有概念，没有后果
- 读完没有继续看下一章的理由
- 文本像说明文、设定文或练笔散文，而不像连载正文
- 脑洞文开篇没有在前三屏亮出核心机制、离谱限制、反差处境或具体死局
- 主角只有冷静、理性、求生，没有嘴脸、欲望、算盘、挑衅或可记忆台词
- 场景像严肃影视分镜：环境镜头漂亮，但卖点迟迟不露、爽点迟迟不转化
- 设定很完整，但没有回答“主角凭什么赢、怎么搞事、对面怎么被迫按他的规则走”
- 一直在 promise，不给第一层 payoff

## 十、优先处理顺序

1. 删解释和总结
2. 修信息释放顺序
3. 修对话信息倾泻和声音同质化
4. 修假钩子和章末收口
5. 处理套话、修饰语和标点滥用
6. 最后才做措辞级润色
