# AI 味行文规则汇总

> 本文档只列规则和例子，不涉及任何具体项目背景。

---

## 1. 句式结构类

### ① 三段式 / 凑三
凡事都要列三项，制造虚假的全面感。

> 剑气凌厉、迅捷、不可抵挡。
> 他眼中充满了愤怒、悲伤和不甘。
> 修炼需要天赋、毅力和机缘。

人写东西通常一项或两项就收手。三项并列一多，AI 味立刻上来。

### ② 否定式排比
用“不是……而是……”“不仅仅是……更是……”绕一圈下定义。

> 这不仅仅是一场战斗，更是两种道的碰撞。
> 这不是逃跑，而是战略转移。

改成直接展示：两柄剑撞在一起，他听见了对方的道意。

### ③ 伴随状语堆叠
“象征着 / 反映着 / 体现着 / 预示着”连用，伪造深度。

> 阵法的光芒逐渐黯淡，象征着上古文明的衰落，反映着天道的无常，暗示着更深的危机。

一个“着”就够了，三个并排基本是 AI。

### ④ 虚假范围
“从 X 到 Y”并列三组以上，但 X 和 Y 不构成有意义的尺度。

> 从炼气到化神，从凡人到仙人，从生到死，这条路充满未知。

### ⑤ 碎句癖
为了制造节奏感，把本可逗号连接的句子全用句号切断。

> 他蹲下来。检查脉搏、瞳孔、四肢。动作快。熟练。不像高中生。

读出来一口气能读完的内容，就别拆成三四个句号。

### ⑥ 系动词回避
用复杂结构绕开简单的“是 / 有”。

> 此处作为宗门弟子修炼的核心场所而存在。
> 这把剑充当了连接两界的媒介。

改成：这里是弟子修炼的地方。这把剑是两界之间的通道。

### ⑦ 同义词循环
同一段落内反复换词称呼同一事物或角色。

> 林逸看向远方。青年握紧了拳头。这位少年天才的眼中闪过一丝坚定。年轻修士深吸一口气。

用“他/她”即可，不要在“主角/青年/少年/年轻人”之间轮换。

### ⑧ 重复强调式短排比
“他是个……。一个……”式作者二次盖章。

> 他是个疯子。一个为了赢连命都不在乎的疯子。

把信息压回角色当前能感知到的动作、疼痛、选择或处境。

### ⑨ 连续排比式自我强调
连续“没有 / 不是 / 更没有”硬抬冷酷感或气场。

> 没有尖叫。没有后退。没有一个人敢动。
> 不是害怕。不是犹豫。更不是怜悯。

保留最有画面的一个结果即可。

### ⑩ 比例式情绪描写
“三分 X 七分 Y”模板表达。

> 他的眼神三分嘲讽，七分不屑。

改成具体表情、动作，或一句更贴角色的对白。

### ⑪ 当……时叙事开场
“当 / 每当 / 正当 / 就在……时 / 的时候，主句”做段落开场。

> 当他睁开眼睛的时候，发现自己躺在陌生的房间里。

改成直接动作、具象场景或角色当下的选择。

### ⑫ 工具来源说明句
“XX 是 / 都是 / 全是 + 用 / 靠 / 凭 / 拿 + 材料 + 动词 + 的”像设定说明牌。

> 那面墙是用旧钢板和铁丝网拼的。

优先把材料与工艺信息揉进动作，或一句短对白。

## 2. 解释与戏剧感类

### ⑬ 破折号滥用
分两种。

**假强调：**

> 他终于明白了——这不是普通的阵法——而是上古大能留下的——足以毁天灭地的禁制。

**解释连接器（“X——解释 X 的 Y”）：**

> 废土上这种地方很多——旧文明留下的建筑群，塌了大半。
> 他把三截钢筋单独拿出来放好——这是明天换盐用的。

多数情况下拆成两个句号。每千字叙述中破折号超过 3 到 4 个，优先检查是否全是解释性用法。

### ⑭ 引号套比喻
用引号给修辞上保险。

> 在她的表情系统里已经算“眼前一亮”了。
> 这一战可谓“惊天动地”。

删掉引号意思不变，就说明引号是 hedge，必须删。

### ⑮ 过度限定
堆叠模糊词回避确定性。

> 这种灵药或许可能在某种程度上对伤势有一定的缓解作用。

一个“可能”就够了。

### ⑯ 解释 / 结论先行
刚发生就下原理和结论，而不是先写现象、反应、代价。

> 他知道，这一刀必须快，因为慢一点就会死。
> 这意味着，规则已经变了。

先写现象、反应、代价，再决定是否需要解释。

### ⑰ 规则推演式解释
“按照剧本 / 直接做不行 / 必须让一切自然发生得……”像作者公开解题。

> 按照剧本，他应该在这里示弱。
> 直接冲过去不行，必须让一切发生得足够自然。

保留必要规则，其他用试探动作和系统反馈来呈现。

### ⑱ 完美判定 / 完美扮演
“完美符合 / 100% 符合 / 完美的恐惧扮演”太像系统替作者鼓掌。

> 他完美符合“恐惧”的判定标准。

改成判定结果、失败风险或旁观者误判。

### ⑲ 作者式技巧 / 机制解释
“这是技巧 / 那是排异感 / 犯了忌讳”给动作贴说明牌。

> 这是老猎人的经验，也是他能活到现在的依仗。

除非是明确内心判断，否则优先改成可见后果。

### ⑳ 动作后作者评价
动作刚发生就评价，削弱现场感。

> 这一刀快得离谱，透着残忍精准，令人胆寒。

把评价换成对手反应或动作结果。

### ㉑ 夸大象征意义
把普通事件升格为“划时代的时刻”。

> 这一战标志着他修炼之路的重要转折点，也象征着他内心的蜕变。
> 这一刻将在历史上留下不可磨灭的印记。

让读者自己感受意义，不要替读者总结。

### ㉒ 设定揭示式旁白
“这就是 X 真相 / 没有什么 A 没有什么 B”替读者总结设定。

> 这就是弱肉强食的真相。
> 这里没有什么规则，没有什么公平。

拆进动作、对话、界面信息或冲突后果里。

## 3. 情绪与人物类

### ㉓ 抽象情绪标签
直接给情绪命名，而不是用动作演出。

> 他感到一阵绝望。
> 她觉得有些不安。
> 他心中涌起一股难以言喻的悲伤。

改成具体动作：他把没点的烟摁灭在桌面上。

### ㉔ 表情模板句
“嘴角勾起一抹 / 眼神闪过一丝 / 脸上浮现……”

> 他嘴角勾起一抹冷笑。
> 她眼神中闪过一丝慌乱。

这是 AI 的默认演出镜头，高频出现。

### ㉕ 通用痛感 / 暴力比喻
痛感和暴力比喻密集，模板化。

> 疼痛像潮水一样把他吞没。
> 那一拳像铁锤一样砸下来。

优先改成可见动作、身体失控、呼吸变化或战术后果。

### ㉖ 通用积极结尾
每个场景结尾都强行燃一下。

> 虽然前路漫漫，但他相信，只要坚持下去，终有一天会到达巅峰。他的眼中重新燃起了希望之火。

改成留白或未解决问题，比希望之火强一百倍。

## 4. 视角与旁白类

### ㉗ 作者旁白盖章
作者跳出来替读者下结论、宣布意义。

> 真正可怕的是，他还没有意识到危险。
> 他不知道的是，命运已经悄然改变。
> 这一刻标志着他人生的转折点。

让读者从动作、结果和他人反应里自己得出判断。

### ㉘ 全知视角悬念钩子
“他不知道的是 / 没人知道的是”上帝视角悬念钩子。

> 他不知道的是，真正的考验还没开始。
> 没人知道的是，危险正在逼近。

从主角实际感知的异常入手，让悬念从场景里长出来。

### ㉙ 开天眼 / 敌方内心
写敌人“感到恐惧”“无法理解”，上帝视角乱切。

> 他们感到极度恐惧，无法理解眼前的一切。

对手情绪只能通过主角观察到的外部反应写：对方手在抖、瞳孔涣散、往后退。

### ㉚ 开天眼式身份塞入
当前视角人物不知道，却直接公布身份或外号。

> 这是道上人称“活阎王”的狠角色。

改成衣饰、称呼、旁人反应或对方自报。

### ㉛ 导演镜头式视角切换
从主角视角突然切到配角脑内或镜头说明。

> 他看得很清楚：这个人要动手了。
> 他们只看到一道残影。

改成外部动作和可见反应。

### ㉜ 脱离人物视角的声音镜头
“一个……声音……炸开 / 响起”像导演镜头给旁白音效。

> 一个低沉的声音在他身后响起。

让声音落到视角人物的耳朵、身体反应或现场动作上。

### ㉝ 影视分镜式转场词
“下一秒 / 与此同时 / 就在这一刻 / 时间仿佛静止”密集出现。

> 与此同时，另一边也动了。
> 时间仿佛在这一刻静止。

不是必错，但密集时会像脚本分镜。能删就删，或换成因果动作。

## 5. 对白类

### ㉞ 对白标签情绪化
“冷笑着道 / 怒喝道 / 幽幽地道”。

> “你说什么？”他冷笑着问道。

70% 以上用“说 / 道”，台词本身能带情绪时，标签别重复。

### ㉟ 信息倾泻 / 如你所知
对话变设定说明书，角色互相讲彼此都知道的事。

> “如你所知，这个世界分为四大境界……”

设定要通过冲突、体验和发现展现，不是角色替作者补课。

### ㊱ 所有角色一个声音
遮住名字分不清谁在说话。每个人都是完整句、书面腔、逻辑清晰。

角色该有口头禅、禁忌词、句式长短差异。

### ㊲ 对话没有潜台词
角色直接说出自己的意思、感受和想要的，表面和含义之间没有差距。

> “我要杀了你，夺走你的宝物。”

更好的写法：“林兄最近机缘不浅啊，不知可否借来一观？”

### ㊳ 单一功能对话
对话只完成一件事，没有关系转变、角色揭示或张力。

每段对话至少同时做两件事：推进情节、揭示角色、建立张力、确立关系、创造潜台词。

## 6. 词汇与描写类

### ㊴ AI 高频词
此外 / 至关重要 / 深入探讨 / 充满活力 / 彰显 / 凸显 / 值得注意的是 / 毫无疑问 / 令人印象深刻 / 不断演变的格局 / 展示 / 宝贵的。

### ㊵ 宣传式描写
旅游宣传册语气，堆大词。

> 青云山坐落于大陆中央，拥有令人叹为观止的自然美景，丰富的底蕴使其成为修士心驰神往的圣地。

改成具体感官：山腰往上灵气浓得能看见，新弟子深吸一口被呛到咳嗽。

### ㊶ 低具体度描写
笼统形容词加大词名词，几乎不传递信息。

> 古朴的客栈。
> 诡异的气息。
> 说不出的感觉。

换成一个可感的具体细节：一处掉漆、一种气味来源、一个声响。

### ㊷ 填充短语
在这个关键的时刻 / 由于……的缘故 / 在……的情况下 / 具有……的能力 / 对……进行了深入的研究。

替换成：这时 / 因为 / 如果 / 能 / 研究了。

### ㊸ Markdown 格式残留
正文里出现 `**关键词**`、`## 标题`、`- 列表项`。

小说正文不应有 Markdown 格式。

### ㊹ 颜文字 / 表情符号
叙述里插入不属于小说的符号。

全部删除。

## 7. 章末与节奏类

### ㊺ 章末作者腔硬抬
“就在这一夜，一切都将改变”“真正的危机才刚刚开始”。

钩子要从局面变化、新风险、新决定里自然长出来，不靠旁白宣布。

### ㊻ 章末无变化
一段写完局面没动，没有下一章理由。

每章结束前，局面和开头相比必须发生变化；章末落点要么是新问题、新揭示、新决定、新风险，要么是动作悬置。

### ㊼ 节奏均匀无变化
每段长度雷同、每句长度雷同，紧张处也是长句，平静处也是短句。

人写的东西是错落的：短句制造紧张感，长句用于舒缓，一个字的段落用于冲击。

## 8. 系统与面板类

### ㊽ 系统面板过密
系统面板 / 判定行出现频率过高，像设定说明书。

> 【宿主：林夜】
> 【力量：12.7】
> 【敏捷：11.3】
> 【任务进度：67%】

系统流可以有面板，但过密会像设定说明书。优先删重复字段和解释性判定。

### ㊾ 系统解释代替剧情
系统替主角分析、总结、提醒，主角自己不用思考。

系统是工具而非主角，信息应推动角色决策，不是替代角色思考。
