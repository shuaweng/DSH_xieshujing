# Rewrite To Style Checklist

## 一、先锁边界

- 核心事实不能变
- 关键情节节点不能变
- confirmed 设定不能乱改
- 不该现在说破的信息不能提前释放

## 二、再锁目标

- 这次是要更顺，还是更冷
- 是要更像网文，还是更收
- 是要去 AI 味，还是要修对白
- 最重要的 1 到 2 层是什么

## 三、常见改写层

### 1. 去 AI 味

- 删三段式凑数
- 删抽象泛化总结
- 删”正确但没必要”的解释
- 拆解释性破折号（”X——解释X的Y”→两句），保留角色声音和引用内文的破折号
- 删引号套比喻（””包裹成语/情绪词），直接使用或换表达

### 2. 句法节奏

- 长短句错开
- 关键句单独落
- 段尾别泄力

### 3. 对白声音

- 让角色说话方式带年龄、身份、关系
- 别让对白讲课
- 别让所有人都一样利索、一样完整

### 4. 信息露出

- 先给效果
- 再给反应
- 最后才给必要原理

### 5. 章末收口

- 别靠作者宣布重要性
- 落在变化、风险、决定或未落地结果上

## 四、改完自检

1. 事实没坏
2. 气质更准
3. 信息没说破
4. 对白没更假
5. 章末没写软
