# Promise Ladder

用于判断一本书的开头 promise 有没有按层落地。

## 第一层：读者为什么继续看

检查：

- 主角是谁
- 主角卡在哪里
- 当前局面最别扭的点是什么
- 第一章末有没有明确继续看的理由

如果这一层没立住：

- 读者连“跟谁走”都不知道
- 也不会在乎后面更大的卖点

## 第二层：这本书和别人有什么不同

检查：

- 核心卖点是什么
- 主角独有路径是什么
- 这条路为什么值得看
- 这种“不同”是被展示出来了，还是只在简介/设定里写着

如果这一层没显形：

- 读者会觉得只是同题材复写
- 即使文笔顺，也很难形成真正留存

## 第三层：promise 是否开始兑现

检查：

- 主角是否已经用这条路解决或撬动了一个局面
- 读者是否已经看到“这条路真的能打”
- 第三章左右是否出现第一层 payoff

如果这一层没落地：

- 前三章容易变成“空头支票”
- 读者会知道作者想写什么，但还没看到结果

## 审稿时的典型判断

### 只做到第一层

- 主角和困局立住了
- 但卖点和差异性还没显形

判断：

- 能看，但抓力有限

### 做到第一层和第二层

- 主角立住了
- 卖点也露头了
- 但第三章还没有第一层 payoff

判断：

- 有 promise，但像空头支票

### 三层都做到

- 主角立住
- 卖点显形
- 第三章开始兑现

判断：

- 黄金三章基本成立

## 对你这个 skill 的实际作用

审稿时不要只说：

- “卖点不错”
- “主角有潜力”

而是要明确判断：

1. 读者为什么继续看
2. 这书和别家有什么不同
3. promise 有没有开始兑现

这三个答案不清楚，就不要轻易给高评价。
