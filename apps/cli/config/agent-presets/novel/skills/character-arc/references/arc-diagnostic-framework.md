# 弧线诊断框架

本文件为 `character-arc` skill 的核心参考。包含弧线定义、诊断工具、常见谎言库、弧线-结构映射、和反模式详解。

---

## 一、弧线类型详解

### 1. 正向变化弧线

角色从"相信谎言"到"接受真相"的旅程。

**七要素**：

| 要素 | 定义 | 检查方法 |
|:---|:---|:---|
| 谎言 | 关于自我或世界的错误信念 | "角色相信什么是错的？" |
| 幽灵 | 造成谎言的背景创伤 | "什么经历让他形成了这个信念？" |
| 想要 | 由谎言驱动的外部目标 | "他以为自己需要什么？" |
| 需要 | 真正能满足他的东西 | "他实际上需要什么？" |
| 催化剂 | 迫使角色面对谎言的事件 | "什么事件让谎言第一次动摇？" |
| 挣扎 | 角色抗拒改变的过程 | "他在哪里加倍坚持旧信念？" |
| 真相 | 角色最终接受的正确认知 | "他在高潮时领悟了什么？" |

### 2. 负向变化弧线（悲剧）

角色有成长的机会但走向堕落。

**六要素**：

| 要素 | 定义 |
|:---|:---|
| 潜力 | 成长的机会（他本来可以…） |
| 缺陷 | 可以克服但未克服的弱点 |
| 诱惑 | 助长缺陷的捷径 |
| 堕落 | 加剧缺陷的一系列选择 |
| 不归点 | 拒绝了最后的救赎机会 |
| 后果 | 缺陷摧毁了他珍视的东西 |

### 3. 平坦弧线

角色已知真相，在考验中坚守，改变世界而非自己。

**五要素**：

| 要素 | 定义 |
|:---|:---|
| 真相 | 角色持有的正确信念 |
| 世界冲突 | 环境挑战这一信念 |
| 考验 | 信念受到极端压力 |
| 影响 | 角色的坚守改变了他人 |
| 验证 | 真相被证明是正确的 |

**注意**：平坦弧线不等于没有弧线。角色没变，但他改变了周围的世界。

## 二、网文弧线爽点校准

网文弧线的核心不是"角色成长"而是"爽点递增"。但好的网文弧线两者兼得。

### 废材逆袭弧线

```
废材确立(1-3章) → 获得金手指(3-5章) → 首次小胜(5-10章)
→ 打脸第一批小人(10-30章) → 遭遇真正强敌(30-50章)
→ 突破瓶颈+更大逆袭(50章+)
```

**爽点校准检查**：
- 废材期是否 ≤5 章？（太长读者跑了）
- 首次小胜的反差是否足够大？
- 打脸节奏是否递增？（第二次比第一次规模更大）
- 每次逆袭后是否有新的困境接上？（避免平淡期）

**弧线校准检查**：
- 主角除了变强，认知变了吗？
- "我天生是废物"这个谎言在哪一章被动摇？被什么事件动摇？
- 主角有没有机会用当初被对待的方式对待弱者？他怎么选的？

### 重生复仇弧线

```
前世悲惨结局(回忆/闪回) → 重生节点 → 利用先知布局(5-20章)
→ 清算小仇人(20-40章) → 遭遇前世未知的变数(40-60章)
→ 对决终极仇人(60章+)
```

**爽点校准检查**：
- 前世交代是否 ≤3 章？（太长读者不耐烦）
- 布局的智商快感是否逐步升级？
- 是否有"先知失效"的意外？（纯先知碾压太无聊）

**弧线校准检查**：
- 主角是纯复仇机器，还是在新生中建立了新的羁绊？
- 有没有一个"前世没有的关系"让主角在复仇和保护之间矛盾？
- "所有人都会背叛我"这个谎言有被挑战吗？

### 扮猪吃虎弧线

```
低调示弱(持续) → 被误判小看(多次) → 危机迫使暴露(关键点)
→ 众人震惊(高潮) → 重新低调(循环)
```

**爽点校准检查**：
- 隐藏实力的理由是否合理？
- "蓄势"的长度和"释放"的爽度是否成正比？
- 暴露频率是否控制得当？（太频繁→扮猪不成立）

**弧线校准检查**：
- 隐藏行为本身是否反映了一个内在信念？（"低调才安全"）
- 故事是否最终逼迫主角放弃隐藏？这个转变有意义吗？

### 升级流弧线

```
当前境界瓶颈 → 获得机缘/突破契机 → 实力大幅提升
→ 碾压旧困境 → 新境界新困境(循环)
```

**爽点校准检查**：
- 每次突破的过程是否有差异化？（不能每次都是"吞丹药闭关"）
- 境界描述是否有实感？（不是纯数字堆叠）
- "更强的对手"是否有独立人格？（不是简单的战力数值+1）

**弧线校准检查**：
- 实力突破是否伴随认知突破？
- 主角对"力量"的理解是否在变化？
- 除了"变更强"，主角是否有内在目标的演变？

## 三、常见谎言库

### 通用角色谎言

| 谎言 | 常见幽灵 | 对应需要 |
|:---|:---|:---|
| "我不值得被爱" | 被遗弃/忽视 | 接受自己值得被爱 |
| "权力是唯一的保护" | 曾经无力保护重要的人 | 学会信任和依靠他人 |
| "信任会导致背叛" | 被亲近的人出卖 | 重新建立信任的能力 |
| "我的价值来自成就" | 只有表现好才被认可 | 接受自身的内在价值 |
| "世界是敌意的" | 从小在恶劣环境中求生 | 发现世界中的善意 |
| "我不需要任何人" | 自给自足是唯一可靠的 | 接受人际连接的意义 |
| "示弱等于死亡" | 曾因脆弱而被伤害 | 学会脆弱也是一种力量 |

### 网文高频角色谎言

| 谎言 | 常见弧线 | 打破方式 |
|:---|:---|:---|
| "我天生就是废物" | 废材逆袭 | 用行动证明价值，但不是用实力碾压 |
| "只有变强才不会被欺负" | 升级流 | 遇到力量解决不了的困境 |
| "所有人都会背叛我" | 重生复仇 | 新生中遇到不计代价信任他的人 |
| "实力就是一切" | 无情强者 | 因为纯靠实力而失去重要的东西 |
| "只要我够低调就安全" | 扮猪吃虎 | 被迫暴露后发现被认可也不错 |
| "弱者不配拥有好东西" | 丛林法则 | 一个"弱者"救了他的命 |
| "前世的错不可挽回" | 重生文 | 在新生中把前世的遗憾弥补了 |
| "感情是弱者的累赘" | 冷酷主角 | 因为拒绝情感而做出错误判断 |

## 四、弧线-结构映射表

### 传统弧线映射

| 故事节拍 | 弧线节拍 | 诊断要点 |
|:---|:---|:---|
| 铺陈 | 谎言确立，想要激活 | 开场是否清楚展示了谎言？ |
| 第一转折 | 角色投入，仍相信谎言 | 进入新世界后谎言是否被强化？ |
| 上升动作 | 追求想要的 | 是否有小胜利来强化谎言？ |
| 中点 | 镜像时刻，瞥见真相 | 是否有一个"意识到可能错了"的瞬间？ |
| 复杂化 | 谎言与真相冲突 | 是否有事件同时支持和否定谎言？ |
| 至暗时刻 | 谎言彻底失败 | 是否有一个"旧方法完全行不通"的危机？ |
| 高潮 | 接受真相 / 拒绝真相 | 角色的最终选择是否基于新认知？ |
| 结局 | 展示新自我 | 是否用行动（非旁白）证明了转变？ |

### 网文弧线映射（以废材逆袭为例）

| 章节区间 | 弧线节拍 | 爽点节拍 | 双轨检查 |
|:---|:---|:---|:---|
| 前 5 章 | 废材身份确立，谎言("我是废物")形成 | 被羞辱，积蓄愤怒 | 读者既代入又愤怒？ |
| 5-10 章 | 获得金手指，谎言首次动摇 | 第一波小爽 | 金手指是否挑战了谎言？ |
| 10-30 章 | 初步逆袭，谎言持续被动摇 | 持续打脸爽感 | 打脸同时推进内在变化？ |
| 30-50 章 | 遭遇强敌，真相开始浮现 | 紧张感，大危机 | 强敌是否逼主角面对深层恐惧？ |
| 50 章+ | 接受真相（或新版本的谎言） | 大规模逆袭 | 最终胜利是否需要内在转变？ |

## 五、反模式详解

### RP-1：被告知的弧线

**表现**：作者通过旁白告诉读者"他变了"，但角色的行为模式没变。

**典型句式**：
- "经过这件事，他终于明白了…"
- "从此以后，他再也不是从前的自己了"
- "他的眼神中多了一丝成熟"

**修法**：删掉旁白。设计一个场景，让角色面对和过去类似的选择，做出不同的决定。

### RP-2：万能导师

**表现**：角色的转变完全靠导师的一番话。

**修法**：导师可以指明方向，但领悟必须是角色自己走到的。把导师的话变成种子，在后续事件中生根。

### RP-3：创伤=转变谬误

**表现**：因为发生了可怕的事，角色就自动变了。

**修法**：创伤创造条件，但弧线是角色如何应对创伤。同样的创伤可以导致成长也可以导致堕落——选择才是弧线。

### RP-4：完美主角

**表现**：主角没有有意义的缺陷。没有谎言就没有弧线。

**修法**：即使令人钦佩的角色也需要盲点。盲点不是道德缺陷，可以是认知局限。

### RP-5：瞬间顿悟

**表现**：角色毫无铺垫地突然"想通了"。

**修法**：提前埋下种子——几个小事件逐步动摇谎言。真相的到来回顾起来应该是水到渠成。

### RP-6：数值膨胀代替成长（网文）

**表现**：主角境界越来越高，但性格、认知、待人方式没有任何变化。

**信号**：
- 第 1 章的主角和第 100 章的主角除了战力没有区别
- 每次突破只改变战力数值，不改变角色的世界观
- 主角对力量的态度从头到尾一模一样

**修法**：每个大境界突破绑定一个认知转变。例：突破金丹后主角第一次理解"修行不只是变强"。

### RP-7：复仇机器（网文）

**表现**：重生主角从头到尾只有复仇，没有犹豫，没有新的羁绊。

**信号**：
- 主角从不质疑自己的复仇行为
- 没有任何新关系能影响主角的决策
- 复仇清单像购物清单一样逐个划掉

**修法**：安排一个前世没有的关系，让主角在复仇计划和保护新关系之间产生矛盾。

### RP-8：全能无敌综合症（网文）

**表现**：主角太强了，没有任何事情构成真正威胁。

**修法**：实力上的无敌不等于内心的无敌。设计一个打不赢的困境——不是武力上的，而是情感上、道德上、选择上的。

### RP-9：降智陪衬

**表现**：为了衬托主角聪明/强大，配角集体降智。

**信号**：
- 反派犯低级错误，但按设定他不该犯
- 所有人都看不出主角的实力，但线索很明显
- 配角的反应千篇一律（"不可能！"）

**修法**：反派的决策必须是他知道的信息下的最优解。配角的反应必须基于他们自己的立场和信息。

## 六、配角功能定位速查

| 功能类型 | 定义 | 对主角弧线的作用 |
|:---|:---|:---|
| 镜像角色 | 走了主角"另一条路"的人 | 展示谎言的后果/真相的价值 |
| 催化剂 | 推动主角面对谎言的人 | 制造无法回避的冲突 |
| 对照组 | 相信同样的谎言但结局不同 | 强化主角选择的意义 |
| 信息传递者 | 合理地释放关键信息 | 推进情节+挑战主角认知 |
| 情感锚点 | 给主角提供情感动力 | 让主角的行动有情感根基 |
| 世界代言人 | 代表世界观/社会规则 | 构建谎言存在的土壤 |
