# Editorial Rubric — 量化评分体系

默认按 5 个维度打分，每项 100 分，按权重折算成基础总分。
总原则：

- 采用**挑刺扣分制**——从 70 分起扣，发现问题就减分
- 60 分代表具备继续推进的基础商业价值
- 80 分以上必须有明显亮点，不轻给
- 没有惊艳表现时，默认在 40-70 区间判断
- 样本不完整时，不做伪终审

---

## 一、平台与题材匹配（权重 25%）

按三层漏斗判断。

### 打分阶梯

| 分段 | 标准 | 典型表现 |
|:---|:---|:---|
| **0-39** | 平台错位严重 | 外观和情绪都不成立；写给自己看的文艺向 |
| **40-59** | 有局部可取 | 底层情绪对，但包装古早或标签错位 |
| **60-79** | 基本同频 | 题材方向对、情绪核心成立、包装无明显违和 |
| **80+** | 强平台感 | 卖点一句话清楚、标签命中、情绪和包装都锐利 |

### 硬性扣分触发器

| 发现 | 直接扣分 |
|:---|:---|
| 标签完全无法命中平台任何热门方向，且底层情绪也弱 | **直接 ≤30 分** |
| 古早包装（退婚/山崖/机械系统"叮恭喜宿主"） | **扣 15-20 分** |
| 设定违和出戏（严肃修仙掏加特林、无铺垫强行缝合） | **扣 15-20 分** |

---

## 二、大纲与主线寿命（权重 20%）

### 打分阶梯

| 分段 | 标准 | 典型表现 |
|:---|:---|:---|
| **0-39** | 灾难级 | 完全没主线，主角无头苍蝇，或大纲只是设定集 |
| **40-59** | 不及格 | 有初步目标，但缺乏换地图钩子，中期极易崩盘水字数 |
| **60-79** | 工业及格 | 升级体系明确，有阶段性 BOSS，卷目标可见 |
| **80+** | 强架构 | 主线极具张力，每卷冲突服务于主角核心动机 |

### 硬性扣分触发器

| 发现 | 直接扣分 |
|:---|:---|
| 主角像提线木偶，无主观能动性 | **扣 20-30 分** |
| 大纲只是世界观设定集，无起承转合 | **扣 20-30 分**（但如果正文主线明确，触发"正文免死金牌"，仅扣 10 分大纲规范分）|
| 看不到中后期展开空间，主线只有新手村恩怨 | **扣 15-20 分** |

---

## 三、黄金三章留存力（权重 25%）

### 打分阶梯

| 分段 | 标准 | 典型表现 |
|:---|:---|:---|
| **0-39** | 赶客级 | 说明文开局、第三章没冲突、金手指未亮出 |
| **40-59** | 拖沓级 | 有冲突但老套，金手指爽感反馈太慢，虐点过重 |
| **60-79** | 工业及格 | 切入点好、冲突明确、金手指带来直接期待感 |
| **80+** | 神级钩子 | 情绪拉扯完美，第一章就死死抓住读者 |

### 硬性扣分触发器

| 发现 | 直接扣分 |
|:---|:---|
| 第一章出现连续大段纯背景说明（说明文开局） | **扣 25-30 分** |
| 第三章结尾仍无有效核心冲突 | **扣 30-40 分** |
| 前三章只受虐铺垫、无任何爽点反馈 | **扣 15-20 分** |
| 前三章**重复疲劳**（冲突类型重复 / 解法类型重复 / arena 重复 / 章末钩子换皮） | **每项 扣 10 分** |

### 重复疲劳四维检测

必须逐项显式检查：
1. **冲突类型**是否重复（三章都是"被人看不起→打脸"）
2. **解法类型**是否重复（三章都靠同一招）
3. **arena** 是否重复（三章都在同一个场景）
4. **章末钩子**是否只是换皮（三章结尾都是"更强的敌人出现"）

## 四、卖点与爽点转化效率（权重 15%）

### 打分阶梯

| 分段 | 标准 | 典型表现 |
|:---|:---|:---|
| **0-39** | 毒点级 | 设定极其累赘、金手指无爽感转化、强行缝合违和 |
| **40-59** | 老套级 | 毫无新意的流水线设定（普通签到系统） |
| **60-79** | 微创新级 | 一句话讲清卖点，经典套路中有不错的微创新 |
| **80+** | 惊艳级 | 极具反差且逻辑自洽，设定本身就是商业卖点 |

### 硬性扣分触发器

| 发现 | 直接扣分 |
|:---|:---|
| 金手指无效化（设定好听但对剧情无即时收益） | **扣 25-30 分** |
| 设定违和出戏（反差大于自洽，世界观铺垫不足） | **扣 20-30 分** |
| 核心梗讲不清（解释半天还不明白） | **扣 15-20 分** |

---

## 五、文风与可持续读感（权重 15%）

### 打分阶梯

| 分段 | 标准 | 典型表现 |
|:---|:---|:---|
| **0-39** | 灾难级 | 视角频繁乱切、大段旁白、人物全是标签 |
| **40-59** | 干瘪级 | 勉强通顺但全是"告知"非"展示"，像流水账 |
| **60-79** | 工业及格 | 行文流畅，有代入感，能通过事件立住主角 |
| **80+** | 神级代入 | 暧昧拉扯精彩，人物血肉丰满，情绪感染力极强 |

### 硬性扣分触发器

| 发现 | 直接扣分 |
|:---|:---|
| 同章内频繁无意义视角切换（上帝视角乱切） | **扣 25-30 分** |
| 人物全靠旁白贴标签（"他很高冷""她很聪明"） | **扣 15-20 分** |
| 女性角色纯花瓶/工具人，互动无张力 | **扣 10-15 分** |
| 优秀的暧昧拉扯/修罗场/势均力敌关系 | **加 10-15 分** |

---

## 红旗与加减分结算

### 致命毒点（独立于维度评分，叠加扣分）

| 毒点 | 扣分 | 说明 |
|:---|:---|:---|
| 绿帽倾向 | **-100 分** | 强制触发最低档评级 |
| 极度虐主憋屈 | **-30~50 分** | 长期压抑不给释放 |
| 主线缺失 | **-15~20 分** | 主角无长期目标 |
| 主角与冲突缺失 | **-15~20 分** | 前三章无明确主角形象或核心冲突 |

### 合规风险（独立扣分）

| 风险 | 扣分 |
|:---|:---|
| 过度色情/黄暴 | **-40~50 分** |
| 涉及现实政治/敏感历史 | **-40~50 分** |
| 老作者文笔断崖式退步 | **-10~15 分** |

### 老作者阶梯加权

仅在"文风同源且保持水准"时生效。**跨题材转型时加分减半**。

| 级别 | 历史成绩 | 加分 |
|:---|:---|:---|
| **T0 神格** | 十万均/万均/平台爆款 | **+15~20 分** |
| **T1 精品** | 三千均精品/番茄十万在读 | **+10~15 分** |
| **T2 完本** | 千均/有几本完本 | **+5 分** |
| **跨界** | 实体/传统出版大佬来写网文 | **+5~10 分**（但必须苛审网文节奏） |

### 爽感加分项

| 加分项 | 加分 |
|:---|:---|
| 优秀的暧昧/多女主互动（不脸谱化） | **+10~15 分** |
| 关系张力强（势均力敌、修罗场） | **+5~10 分** |
| 小众题材但完成度惊人 | **+5~10 分** |
| 微创新成立且转化效率高 | **+5~10 分** |

---

## 总分计算

```
基础总分 = 平台匹配x25% + 大纲x20% + 黄金三章x25% + 卖点x15% + 文风x15%
最终总分 = 基础总分 + 红旗扣分 + 加减分项
```

## 档位映射

| 分数 | 档位 | 含义 |
|:---|:---|:---|
| **< 40** | 扑街货 | 触犯红线，或选题/执行灾难 |
| **40-59** | 暂时无法签约 | 选题自嗨/小众，节奏/文笔不到位 |
| **60-79** | 凑活签吧 | 踩中风口，工业流水线水平 |
| **80-94** | 速更，夜不能寐 | 选题极佳，节奏精妙，期待感拉满 |
| **≥ 95** | 白金之资 | 极少触发，选题+执行+创新全面惊艳 |
