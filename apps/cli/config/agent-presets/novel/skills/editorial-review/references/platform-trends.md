# 平台趋势评估框架

本文件供 editorial-review 步骤 2（平台匹配度测试）使用。
**不硬编码具体数据**——数据会过期。提供的是评估方法论和判断维度。

---

## 一、主流网文平台定位速查

| 平台 | 核心受众 | 付费模式 | 节奏偏好 | 留存关键 |
|:---|:---|:---|:---|:---|
| 起点中文网 | 男性为主，18-35 | 订阅制（首订→均订） | 中快节奏，前三章定生死 | 首订转化率、追读比 |
| 番茄小说 | 下沉市场，全年龄 | 免费+广告分成 | 快节奏，短章 | 完读率、在读量 |
| 晋江文学城 | 女性为主 | 订阅制 | 可慢热但必须有情感张力 | 收藏转化率 |
| 刺猬猫 | 二次元/ACG向 | 订阅制 | 偏日轻/二次元 | 圈层认同 |
| 七猫/飞卢 | 免费读者 | 广告分成/VIP | 爽文/快餐化 | 在读量留存 |

> **注意**：以上是框架性定位。具体政策（分成比例、签约门槛等）请以平台最新公告为准。

## 二、题材匹配三层测试法

### 第一层：表层标签匹配
- **提取方法**：从作品中提取 2-3 个核心标签（如"都市+系统+无敌"）
- **匹配判定**：这些标签组合在目标平台的热门榜/新书榜上是否有同类作品活跃？
- **阳性标志**：畅销榜上有同类标签组合的作品在近 3 个月内上架
- **阴性标志**：该标签组合在平台上完全没有对标品，或对标品全部扑街

### 第二层：底层情绪内核推演
- **核心问题**：这部作品给读者的核心情绪承诺是什么？
- **常见情绪内核**：
  - 翻身/逆袭：从底层到顶端的快感
  - 掌控/征服：主角逐步掌控一切
  - 探索/解谜：发现新世界的好奇心
  - 复仇/雪恨：压抑后的爆发
  - 暧昧/心动：关系拉扯的甜感
  - 守护/温馨：保护在意之人
- **匹配判定**：该情绪内核是否契合平台主流读者的消费倾向？
  - 起点男频核心情绪：翻身、掌控、征服
  - 番茄核心情绪：爽、直接、不费脑
  - 晋江核心情绪：心动、虐恋、HE/BE 讨论

### 第三层：包装新鲜度检测
- **古早包装红旗**：退婚开局、废柴觉醒、老爷爷戒指、"叮，恭喜宿主"
- **新鲜度判断**：同一个套路是否还有市场？关键看两点：
  1. 近 3 个月同套路新书是否还能上架拿推荐？
  2. 是否在旧套路上有足够的"微创新"？
- **微创新判断标准**：不是改个皮，而是核心机制/爽点释放方式有差异

## 三、趋势判断维度（供分析用）

当需要判断某个题材方向的市场状态时，从以下维度考察：

### 3.1 供需热度
- **高供给 + 高需求**（红海）：竞争激烈，必须有明确差异化
- **低供给 + 高需求**（蓝海）：最佳时机，但可能有平台政策限制
- **高供给 + 低需求**（过饱和）：需极强执行力才能突围
- **低供给 + 低需求**（冷门）：除非极致执行，否则不建议入场

### 3.2 生命周期判断
- **爆发期**：新题材/新玩法刚出现，跟进的人少，成功率高
- **成长期**：榜单出现模仿者，但读者需求未饱和
- **成熟期**：头部作品固化，新入场者只能吃尾部流量
- **衰退期**：读者审美疲劳，跟风作大面积扑街

### 3.3 情绪内核 vs 表层标签
- **重要判断**：同一个情绪内核可以换不同的表层标签
  - 例：翻身爽感 → 都市重生 / 赘婿逆袭 / 修仙废材 → 核心体验相同，包装不同
  - 评估时应关注**情绪内核是否有市场**，而非**具体标签是否过气**

## 四、平台适配检查清单

在评审时逐项检查：

- [ ] **章节长度**：是否符合平台习惯？（起点 2000-4000 字/章，番茄 1000-2000 字/章）
- [ ] **更新节奏预期**：作者能否维持平台期望的更新频率？
- [ ] **开篇节奏**：前三章是否在平台容忍度内建立冲突？
- [ ] **题材合规**：是否触碰平台禁区？（政治敏感、色情、暴力标准因平台而异）
- [ ] **读者代入锚点**：主角的年龄/身份/处境是否匹配目标读者？
- [ ] **竞品参照**：能否找到 2-3 部同平台同题材的成功作品？

## 五、使用方式

1. **不要照抄数据**：本文件不提供"起点玄幻首订均 800"这类具体数据——这些数据每季度都在变
2. **用框架做判断**：按三层测试法和趋势维度分析作品与平台的匹配程度
3. **结合作者信息**：如果作者提供了目标平台和参考竞品，优先用那些信息做评估
4. **不确定时标注**：如果信息不足以判断某个维度，在报告中标注"信息不足，建议作者补充"
