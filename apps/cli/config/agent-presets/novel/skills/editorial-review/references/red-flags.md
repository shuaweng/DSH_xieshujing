# Red Flags — 量化扣分与加分清单

本文件供 editorial-review 步骤 7 使用。每个红旗必须显式检查，检出后按本文件的分值扣/加分。

---

## 一、绝对高危毒点（任何一项检出即大幅扣分）

| 毒点 | 扣分 | 判定标准 |
|:---|:---|:---|
| **绿帽倾向** | **-100 分** | 主角的女角色有实质出轨或与其他男性暧昧倾向。强制触发最低档评级。 |
| **极度虐主憋屈** | **-30~50 分** | 为制造挫折强行压抑主角，长期不给爽点释放，让主角任人欺凌。扣分与压抑时长成正比。 |
| **主线缺失** | **-15~20 分** | 主角无明确行为动机和长期目标，像无头苍蝇到处乱走。 |
| **主角与冲突缺失** | **-15~20 分** | 前三章无凸显明确主角形象，或开局完全没有核心冲突。 |
| **长期 promise 不兑现** | **-10~15 分** | 钩子抛了一堆，但几十章都不给第一层回报。 |

## 二、结构类风险

| 风险项 | 扣分 | 判定标准 |
|:---|:---|:---|
| 主角长期动机缺失 | **-15~20 分** | 主角没有驱动力，被剧情推着走。 |
| 卷目标不清 | **-10~15 分** | 当前卷到底在打什么仗说不清楚。 |
| 大纲像设定集 | **-10~20 分** | 只罗列世界观而无起承转合。如果正文有主线则仅扣 10 分。 |
| 中短期冲突链断裂 | **-10~15 分** | 小冲突解决了但没有新冲突接上，出现真空期。 |
| 主线寿命明显不足 | **-10~15 分** | 只有新手村小恩怨，看不到中后期展开。 |
| 只靠一个场景语法反复刷模板 | **-10~15 分** | 每章都是同一模式的冲突→解决→升级。 |

## 三、开篇与留存类风险

| 风险项 | 扣分 | 判定标准 |
|:---|:---|:---|
| 第一章说明文开局 | **-25~30 分** | 连续大段纯背景设定/修为介绍。 |
| 卖点显形太慢 | **-10~15 分** | 第三章结束金手指仍未亮出有效反馈。 |
| 前三章冲突类型重复 | **-10 分** | 三章都是同类型冲突（如都是被看不起→打脸）。 |
| 前三章解法类型重复 | **-10 分** | 三章都靠同一招/同一机制解决问题。 |
| 前三章 arena 重复 | **-10 分** | 三章都在同一场景展开。 |
| 章末钩子连续换皮 | **-10 分** | 三章结尾都是同一模式的悬念。 |
| 只有 promise 没有第一层 payoff | **-10~15 分** | 一直在许诺但前三章内不给任何回报。 |
| 古早包装 | **-15~20 分** | 退婚/废修为/山崖/"叮恭喜宿主"。 |

## 四、卖点与设定类风险

| 风险项 | 扣分 | 判定标准 |
|:---|:---|:---|
| 金手指无效化 | **-25~30 分** | 设定好听但不能迅速转成主角实际利益。 |
| 核心梗讲不清 | **-15~20 分** | 设定解释半天还不明白。 |
| 设定违和出戏 | **-20~30 分** | 强行缝合，反差大于自洽。 |
| 概念强于剧情转化 | **-10~15 分** | 脑洞很好但对剧情推进没贡献。 |

---

## 五、文风与代入类风险

| 风险项 | 扣分 | 判定标准 |
|:---|:---|:---|
| AI 味重 | **-10~20 分** | 参考 style-audit 的 P1-P15 模式检测。 |
| 解释欲过强 | **-10~15 分** | 大段作者视角说明，代替故事展示。 |
| 对话信息倾泻 | **-10~15 分** | 角色对话沦为作者向读者传递设定的管道。 |
| 说破太早 | **-10~15 分** | 悬念还没酿熟就急着告诉读者答案。 |
| 视角频繁乱切 | **-25~30 分** | 同章内无意义切换视角。 |
| 人物全靠标签硬贴 | **-15~20 分** | 旁白说"他很高冷"但事件不支持。 |
| 感情戏/互动像功能块 | **-10~15 分** | 女性角色只出来喊"好厉害"。 |

## 六、商业化与合规类风险

| 风险项 | 扣分 | 判定标准 |
|:---|:---|:---|
| 过度色情/黄暴 | **-40~50 分** | 大段露骨描写，极易导致封书。 |
| 涉及现实政治/敏感历史 | **-40~50 分** | 对现实政治或敏感历史进行影射或直接描写。 |
| 题材与平台读者明显错位 | **-10~15 分** | 在男频平台写纯文艺/女性向。 |

## 七、加分项

| 加分项 | 加分 | 判定标准 |
|:---|:---|:---|
| **T0 神格作者（同题材）** | **+15~20 分** | 十万均/万均/平台爆款。 |
| **T1 精品作者（同题材）** | **+10~15 分** | 三千均精品/番茄十万在读。 |
| **T2 完本作者** | **+5 分** | 千均/有几本完本。 |
| **跨界大佬** | **+5~10 分** | 实体出版转网文（但必须苛审网文节奏）。 |
| **优秀暧昧/多女主互动** | **+10~15 分** | 女角色不脸谱化，暧昧拉扯/修罗场精彩。 |
| **关系张力强** | **+5~10 分** | 势均力敌的交锋、层次丰富的人物关系。 |
| **多角色群像不脸谱化** | **+5~10 分** | 配角有独立动机和声音。 |
| **小众题材完成度惊人** | **+5~10 分** | 冷门题材但极致执行。 |
| **微创新成立且转化高效** | **+5~10 分** | 旧套路上的新花样，且能快速转成剧情收益。 |

---

## 使用规则

1. **每项必须显式检查**：在报告中标注"检出 / 未触发"
2. **扣分可叠加**：一部作品可能同时踩多个红旗
3. **同一问题不重复扣分**：如果某问题已在维度评分中扣过，红旗不再额外扣同一笔
4. **跨题材衰减**：老作者加分在跨题材时减半
5. **扣分有上限**：除绿帽(-100)外，单项扣分不超过 50 分
