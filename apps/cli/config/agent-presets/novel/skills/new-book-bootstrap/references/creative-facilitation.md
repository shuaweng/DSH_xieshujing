# 创意引导框架

本文件为 `new-book-bootstrap` 步骤 2（交互式创意共创）提供实质性框架。
Agent 在引导用户打磨设定时，应参考对应板块的框架，而非空问。

---

## 一、金手指深度设计框架

网文的金手指是核心卖点。不能只收集"一句话核心机制"就完事——必须在 5 个维度上逐一和用户敲定。

### 1. 核心概念

- **本质**：系统？神器？血脉？传承？重生记忆？
- **来源**：从哪来的？为什么主角能得到？
- **独有性**：为什么只有主角能用？如果别人也能用，主角的优势在哪？

### 2. 功能模块

按阶段拆分，防止一上来就全能：

| 阶段 | 功能 | 爽点定位 |
|:---|:---|:---|
| 前期（基础功能） | 给主角初始优势，但优势有限 | 小胜、意外、让人好奇 |
| 中期（进阶功能） | 解锁更多能力，但伴随更大代价 | 爆发、翻盘、超出预期 |
| 后期（终极形态） | 影响世界规则级别的能力 | 格局、震撼、回收前期伏笔 |

**关键问题**：每个阶段解锁的条件是什么？是修为到了自动解锁，还是需要特定机缘/代价？

### 3. 平衡性设计

金手指没有代价 = 读者觉得无聊。必须设计限制：

- **消耗**：用一次要付出什么？（寿元/灵力/因果/精神力/冷却时间）
- **使用条件**：什么情况下不能用？（有旁人时不能用？需要特定状态？一天只能用 N 次？）
- **副作用**：过度使用会怎样？（反噬？暴露？引来更大危险？）
- **限制的叙事价值**：限制本身能否产生好看的场景？（"明明有外挂但现在用不了"是天然的压力场景）

### 4. 进化路线

金手指应该有清晰的版本迭代，让读者有"升级期待"：

```
1.0（初始）→ 2.0（觉醒）→ 3.0（完全体）
```

每次进化应该改变的不只是数值，而是**能力的质变**。

- 1.0 → 2.0：从"辅助工具"变成"战略武器"
- 2.0 → 3.0：从"个人能力"变成"改变世界规则"

**关键问题**：进化的触发条件是什么？读者能提前猜到下一阶段吗？（适度可预测 = 期待感）

### 5. 视觉/感知表现

金手指在文中怎么呈现？不是干巴巴报属性面板：

- 有 UI 界面的系统流：界面风格、交互方式、音效、特效
- 无 UI 的传承/血脉流：激活时的身体感受、外在变化、旁人能看到什么
- 重点：**第一次出现时的描写决定了读者对金手指的第一印象**

## 二、角色深度设计框架

角色不只是"名字+身份+性格标签"。必须在以下维度上有实质内容。

### 1. 核心三要素（必填）

| 要素 | 问题 | 网文翻译 |
|:---|:---|:---|
| **欲望** | 主角想要什么？ | 读者跟着追的目标 |
| **难点** | 什么在阻碍他？ | 读者替他着急的困境 |
| **成就** | 他能获得什么？ | 读者觉得值的爽点 |

### 2. 角色弧线（强烈建议填）

弧线 = 角色在压力下从一种人变成另一种人。没有弧线的主角 = 升级机器。

#### 弧线组件

- **谎言**：角色持有的错误信念（例："我天生就是废物"）
- **想要**：由谎言驱动的外部目标（例："变强到没人敢欺负我"）
- **需要**：真正能满足他的东西（例："理解力量的真正意义"）
- **幽灵**：造成谎言的过去创伤
- **催化剂**：迫使角色面对谎言的事件
- **挣扎**：角色抗拒改变的过程（改变是艰难的）
- **真相**：角色最终接受的正确认知

#### 四种网文经典弧线

根据题材，建议用户从以下弧线中选择或混搭：

| 弧线类型 | 起点 | 核心爽点 | 常见陷阱 |
|:---|:---|:---|:---|
| **废材逆袭** | 被看不起/退婚/废修为 | 反差越大越爽 | 废材期太长；逆袭太容易 |
| **重生复仇** | 带前世记忆重生 | 布局清算的智商快感 | 前世交代太长；复仇对象太多 |
| **扮猪吃虎** | 隐藏实力/装弱 | 揭露时的震惊反转 | 隐藏理由不合理；暴露太频繁 |
| **升级流** | 面临瓶颈/强敌 | 每次突破的递增爽感 | 突破千篇一律；数字膨胀失去实感 |

#### 常见网文角色谎言（可直接选用或改编）

- "我天生就是废物"（废材逆袭）
- "只有变强才不会被欺负"（升级流）
- "所有人都会背叛我"（重生复仇）
- "实力就是一切，感情是弱者的东西"（无情强者）
- "只要我够低调就不会有麻烦"（扮猪吃虎）
- "弱者不配拥有好东西"（丛林法则世界观）

### 3. A面/B面反差（推荐填）

每个重要角色应该有表里两面：

- **A面（表面）**：别人看到的样子
- **B面（内在）**：真实的一面，在特定条件下流露

好的反差示例：
- 表面鲁莽 ↔ 背地里心思缜密，每笔账都记着
- 表面冷漠 ↔ 对特定事物有不合理的执念
- 表面强大 ↔ 内心深处恐惧某件往事

### 4. 拒绝降智原则

- **主角**：不能因为剧情需要而做蠢事。如果要犯错，必须是"在当时信息下的合理判断"
- **反派**：反派的决策必须是已知信息下的最优解。不能因为作者需要主角赢就让反派犯低级错误
- **配角**：不能因为需要衬托主角就集体降智。配角的反应必须基于他们自己的立场和信息

### 5. 关系网设计

不是列一堆名字，而是理清：

- 角色之间的**利益关系**（谁需要谁？谁威胁谁？）
- 角色之间的**信息差**（谁知道什么？谁被蒙在鼓里？）
- 角色之间的**动态变化**（关系会怎么演变？什么事件会改变关系？）

## 三、世界观快检框架

世界规则不能只写"修仙世界，有灵气"。至少在以下 5 个维度上做基础诊断。

### W1：修炼/力量体系

- 大境界划分是什么？每个大境界的**质变**是什么（不是量变）？
- 突破需要满足什么硬性条件？
- 同境界内的战力差距由什么决定？

**最低要求**：至少定义 3-6 个大境界，每个有一句话说清"这个境界能做到什么前一个做不到的事"。

### W2：势力/组织结构

- 主要势力靠什么经济来源维持运转？
- 势力之间的利益关系和制衡是什么？
- 弟子/成员为什么愿意留在组织里？

**最低要求**：至少为主角所在的势力想清楚"钱从哪来、人才怎么选拔、谁说了算"。

### W3：能量/经济体系

- 灵石/灵气从哪来？谁在控制？
- 丹药/法器的品级与修炼境界是否对应？
- 资源的稀缺性前后一致吗？

**最低要求**：前期一块灵石值多少、后期一块灵石值多少，不能前后矛盾。

### W4：种族/血脉（如适用）

- 非人种族的寿命、繁殖方式如何影响社会结构？
- 种族天赋如何塑造其文化和价值观？
- 种族之间的历史恩怨和现实利益关系？

### W5：金手指自洽性

- 金手指的能力上限在哪里？
- 使用代价/限制是什么？
- 为什么别人没有？获取合理性在哪？

**与第一部分"金手指设计框架"联动**：如果步骤 2B 已经做了金手指深设，这里只需确认自洽性。

### 世界观十问（压力测试）

如果用户无法回答其中 5 个以上，说明世界观需要补强：

1. 修炼到顶峰的人在做什么？
2. 普通人的日常生活是什么样？
3. 灵石/能量从哪来？谁控制？
4. 强者为什么不直接碾压一切？
5. 宗门/势力靠什么维持运转？
6. 历史上发生过什么大事？
7. 不同地区有什么差异？
8. 禁忌是什么？违反了会怎样？
9. 天材地宝为什么没被采光？
10. 主角的金手指为什么没被别人发现过？

**注意**：十问不是让用户一次性回答，而是在交互过程中自然带出。Agent 发现世界观薄弱时，挑最关键的 2-3 个问。

## 四、预期锚定

### 什么是预期

预期 = 作者对这本书最初的愿景和执念。它不是大纲，不是设定，而是"我为什么想写这本书"。

### 预期的作用

1. **防漂移**：长篇写到中期最容易跑偏。预期是最便宜的纠偏锚点——每开始新阶段时回来翻一翻，确认方向没跑偏
2. **做减法的依据**：当设定越堆越多时，回到预期问自己"这个设定服务于我最初想写的东西吗？"
3. **创意仲裁**：当两个方向都可以走时，选更接近预期的那个

### 预期应该包含什么

| 项目 | 问题 |
|:---|:---|
| 题材边界 | 我想写什么类型？绝对不想碰什么类型？ |
| 核心体验 | 读者看我这本书，最该获得什么体验？（爽？烧脑？感动？紧张？） |
| 个人执念 | 我一定要写进去的元素是什么？（某种设定？某个场景？某种关系？） |
| 风格方向 | 想偏哪种感觉？（快节奏升级？慢热布局？轻松搞笑？沉重深刻？） |
| 初步设定 | 已经想好的世界观/角色/机制（即使很粗糙） |
| 绝对不要 | 我讨厌的、绝对不想出现的东西 |

### 何时回顾预期

- 步骤 2 每个子阶段完成后，快速对照预期确认方向
- 卷纲完成后
- 每次大改设定时
- 感觉"写偏了"的时候
