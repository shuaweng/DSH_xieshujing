# Style Seeds For Chinese Webnovel Projects

这份参考不是固定文风，而是给 `STYLE.md` 起草时的**默认 drafting guardrails**。

## 1. 默认优先级

如果项目没有给出更具体要求，优先保证：

1. 叙述顺滑度
2. 网文感
3. 钩子力度
4. 卖点显形速度
5. 主角嘴脸辨识度

## 2. 明确避免的 AI 味

- 少用破折号强行制造震撼感
- 少写“但他们不知道的是”“他还不知道”“真正可怕的是”这类作者腔钩子
- 少用大段原理解释替代情节推进
- 少用抽象总结先行，优先让动作、反应、结果自己说话
- 不要刚出现新设定就解释穿
- 少写同义称谓乱轮换、三段式凑数、否定式排比、宣传式结尾

## 3. 开头与黄金三章护栏

- 脑洞文、废土文、无限流、修仙脑洞文、都市脑洞文，前三屏优先回答：这本书的核心机制/反差/限制是什么
- 开篇可以用 `好消息 / 坏消息 / 离谱限制 / 倒计时 / 赌命机会` 这类网文包装，把卖点说清楚
- 开篇尽快进入当前冲突、危机、机会、异常或不稳定
- 不要开头先铺一大段世界观、体系、历史背景
- 第一章要让主角处境立住，不只是把世界观摆出来
- 第一章要让主角“有嘴脸”：贱、狂、损、冷幽默、疯批、克制狠人等至少有一种明确可感知气质
- 第二章要让项目卖点开始显形，而不是继续热身
- 第三章要让前面 promise 开始兑现，不能一直欠账
- 开头的继续读理由应来自人物处境和局面变化，不来自作者提醒“后面很大”
- 前三章应各自承担不同任务，不能连续刷同一种冲突模板
- 如果上一章已经完成一次公开打脸或小胜，下一章优先切到代价、线下后果、真实危险、关系变化或更深规则暴露
- 不要连续两章只是在同一 arena 里把对手、标的物或赌注加码
- 不要连续两章靠同一主解法过关，例如“外挂直接报答案”“配角出手兜底”“主角嘴炮翻盘”
- 第一章、第二章、第三章的章末钩子类型最好有区分：可分别落在异常、兑现、后果/更大风险，而不是连续三章都靠抽象悬念

## 4. 移动端段落与节奏规则

- 默认按手机阅读优化段落
- 大多数段落控制在一到两屏短段内，不轻易堆文字墙
- 长段用于铺垫与描写，短段用于动作、对话、转折和情绪爆点
- 最狠的一句、最大的转折、最关键的情绪爆发，可以单独成行
- 关键信息尽量放在段首或段尾，不要埋在中段解释里

## 5. 对话与人物声音规则

- 每句对话独立成行，说话人和说的话尽量在同一行
- 长对白应拆句，并插入动作、表情、反应和现场压力
- 不让所有角色说出同一种“干净、完整、正确”的台词
- 对话优先承担推进、试探、遮掩、逼迫，不承担说明书功能
- 用身份、年龄、关系和当下情绪压出声音差异

## 6. 钩子原则

- 钩子最好来自“马上会发生的具体后果”
- 钩子要和当前人物目标或当前风险有关
- 不要用作者旁白硬宣布“大事要来了”
- 章末优先停在 `问题 / 决定 / 揭示 / 反转 / 风险升级`，而不是抽象感叹

## 7. 信息释放原则

- 先让读者看到效果，再逐步理解原理
- 爽点不要靠解释，先靠现象、反应、后果建立
- 设定只讲当前场景马上会用到的部分，尤其是能让主角翻盘、装逼、拖时间、骗过对手的部分
- 配角不要过早替读者解释主角的独特路线
- 新设定第一次出现时，只给当前场景必须知道的那部分
- 不要把后续章节的价值在本章先讲穿

## 8. 网文味 vs 影视感边界

- 可以有画面，但画面必须服务于危机、机会、误判或爽点
- 不要用连续环境镜头替代卖点展示：天空、废墟、气味、广告牌、旧时代残骸不能占据开篇主体
- 严肃质感不是问题，问题是主角迟迟不主动、卖点迟迟不露、爽点迟迟不兑现
- 网文读者更关心“他凭什么赢、怎么搞事、对面怎么被迫按他的规则走”

## 9. 配角认知与解释欲边界

- 配角可以震惊、误判、怀疑、跟错结论，但不要立刻看透主角路线
- 旁白不要抢在角色反应前先总结意义
- 不要边发生边讲课，先让事情成立，再决定要不要解释

## 10. 适合写进 `STYLE.md` 的每章自检问题

- 这段顺不顺，读者会不会卡住？
- 像网文吗，还是像说明文 / 设定介绍片？
- 主角处境、目标和当前麻烦立住了吗？
- 主角有没有一句话、一个动作或一个判断能让读者记住？
- 有没有解释过头、把后续价值提前说破？
- 卖点和 promise 显形够快吗？
- 本章有没有 payoff，还是只在继续许诺？
- 章末钩子是不是从局面变化里自然长出来的？
