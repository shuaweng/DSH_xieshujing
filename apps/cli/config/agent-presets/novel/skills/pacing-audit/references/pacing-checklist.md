# Pacing Audit Checklist

## 一、单章四问

每章先问：

1. 主角这章要干什么
2. 这章的阻力是什么
3. 这章结尾前发生了什么变化
4. 为什么还得继续看下一章

缺两条以上，这章大概率发虚。

## 二、章节功能判断

这章本来应属于哪类：

- 推进章
- 兑现章
- 转折章
- 铺垫章
- 缓冲 / 消化章

最常见的问题不是“慢”，而是：

- 本来该推进，却只在解释
- 本来该兑现，却只在预热
- 本来该铺垫，却没有埋出后续价值

## 三、场景-续篇故障

### 1. 没有场景，只有续篇

- 一直想、一直总结、一直消化
- 角色没有把决定转成行动

### 2. 没有续篇，只有场景

- 一直冲、一直打、一直出事
- 读者没有消化和重新站位的时间

### 3. 干净胜利

- 场景以简单的“成了”结束
- 没有“但是”或“而且”
- 张力被直接抽空

### 4. 沉溺式续篇

- 长时间内省和复盘
- 但不导向新的决定

## 四、变化检查

一章结束后，至少动一项：

- 资源
- 地位
- 关系
- 认知
- 风险
- 下一步选择

如果什么都没动，就容易像“忙了一章，什么也没发生”。

## 五、爽点与追读检查

### 1. 爽点密度

- 连续几章有没有完全没有兑现点
- 爽点是否全是同一种
- 爽点有没有铺垫和反应

### 2. 追读钩子

- 章末有没有明确继续读理由
- 上一章的钩子，本章是否及时接住
- 钩子是不是一直用同一种模板

### 3. 风险与兑现平衡

- 是否一直预热，不给兑现
- 是否一直兑现，不再抬高风险
- 是否只讲风险，不让角色作出选择

## 六、卷内推进检查

看连续 3-5 章时，优先问：

- 是否更接近卷目标
- 主线有没有被支线拖散
- 这一段是在积累，还是在绕圈
- 最近的升级 / 爽点 / 反转是否开始稀薄

## 七、高风险信号

- 连续多章没有明确变化
- 主角一直在动，但没有新的局面
- 章末一直埋，下一章一直不接
- 爽点干旱期过长
- 每章都像“过渡”，没有真正承担功能

## 八、优先修法

1. 先砍没有功能的过渡段
2. 先补清晰目标和阻力
3. 先让结尾出现明确变化
4. 再补钩子和追读理由
5. 最后才微调段落节奏
