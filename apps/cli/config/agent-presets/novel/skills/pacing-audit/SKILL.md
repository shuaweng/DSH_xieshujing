# Pacing Audit

这不是“节奏快不快”的空话审稿。

它要判断的是：

- 为什么这段读起来发虚
- 为什么这几章看着都在动，其实没推进
- 为什么追读力在掉
- 为什么爽点、风险、兑现和铺垫开始失衡

## 核心目标

重点抓 5 类问题：

1. 目标不清
2. 阻力不升级
3. 变化太小
4. 爽点 / 风险 / 钩子失衡
5. 卷内推进偏线或空转

## 何时使用

优先在这些场景使用：

- “这几章是不是有点水”
- “为什么最近读起来拖”
- “这章有事，但不带我往下看”
- “帮我看这 3 章的节奏有没有问题”
- “卷中段为什么开始发虚”
- “追读感掉了，帮我找原因”

## 不要做的事

- 不要把“节奏”偷换成“句子长短”。
- 不要只盯章末一句话，而忽略整章有没有变化。
- 不要上来直接改稿。
- 不要把单章句法问题误判成卷内节奏问题。
- 不要把所有铺垫章都判成“水”。

## 工作流

### 步骤 0：确认审稿范围

先判断这次是在审：

- 单章
- 连续 2-5 章
- 一段卷内区间

如果用户给的是零散片段，而不是连续正文：

- 先提醒：节奏判断会受样本不完整影响

### 步骤 1：确认这段内容承担什么功能

先判断它本来应该是：

- 推进章
- 兑现章
- 转折章
- 铺垫章
- 缓冲 / 消化章

如果连“这段本来要干什么”都说不清，后面的节奏判断会漂。

如果审稿范围是连续多章（≥ 5 章），同时做 **起承转合映射**：

- 把当前区间映射到起（1-3 章）→ 承（4-14 章）→ 转（1-3 章）→ 合（2-4 章）
- 检查各阶段比例是否合理（详见 `references/plot-modules-and-rhythm.md` 第二部分）
- 检查是否已超过 2 万字（7-14 章）还没到“转”——如果是，标记为**高风险**

### 步骤 2：先做四问检查

对每一章都先问：

1. 主角这章要干什么
2. 这章的阻力是什么
3. 结尾前发生了什么变化
4. 为什么还得继续看下一章

缺两条以上，这章大概率发虚。

### 步骤 3：判断节奏故障属于哪一类

#### A. 目标不清

常见表现：

- 有很多事件，但不知道主角这章到底在争什么
- 场景是热闹的，推进是模糊的

#### B. 阻力不升级

常见表现：

- 一直是同一种轻度麻烦
- 冲突没抬高，读者体感就会变平

#### C. 变化太小

常见表现：

- 结尾和开头相比，局面几乎没动
- 角色忙了很久，但关系、信息、资源、风险都没变化

#### D. 爽点 / 风险 / 钩子失衡

常见表现：

- 连续几章没有一个可感知的兑现点
- 章末一直埋，但下一章不接
- 钩子种类单一，读者开始麻木

#### E. 卷内推进偏线

常见表现：

- 写了几章，但没有更接近卷目标
- 支线越来越多，主线张力越来越弱

### 步骤 4：剧情模块同质化检查

识别当前区间使用了哪些剧情模块（详见 `references/plot-modules-and-rhythm.md` 第三部分），判断：

- 是否连续 3 章以上在用同一种模块（如连续竞技场、连续基建）
- 高强度模块后是否有缓冲（大逃杀/竞技场后是否接了公路游/基建）
- 模块之间的过渡是否有因果关系（上一模块的战利品/代价 = 下一模块的诱因）
- 幕间剧是否放在了正确位置（“合”之后，不在“转”与“合”之间）

六种剧情模块速查：

| 模块 | 特征 | 疲劳阈值 |
|:---|:---|:---|
| 竞技场 | 明牌硬实力对拼 | 连续 > 3 场 |
| 大逃杀 | 资源匮乏下的逃亡反击 | 持续高压 > 5 章 |
| 迷雾局 | 悬疑探秘，敌暗我明 | 线索太多不给揭露 |
| 基建/种田 | 发展实力，反馈感 | 纯种田 > 3 章 |
| 欺诈局 | 心理博弈，做局 | 连续做局显阴暗 |
| 公路游 | 转移地图，温馨日常 | > 3 章需引入冲突 |

### 步骤 5：检查场景-续篇比例

参考场景-续篇思路，判断：

- 是不是全在场景，没有消化
- 是不是全在续篇，没有推进
- 有没有“干净胜利”把张力抽空
- 有没有“沉溺式续篇”把节奏拖住

### 步骤 6：检查多章区间的追读力

优先看：

- 最近几章有没有爽点干旱
- 上一章钩子是否在下一章前部兑现
- 铺垫和兑现是否失衡
- 升级、风险、关系变化是否全部停滞

### 步骤 7：输出修法，不直接改稿

输出时优先说明：

1. 断点从哪里开始
2. 主要故障属于哪类
3. 应该先删什么
4. 应该先补什么
5. 该接 `scene-drive`、`chapter-execution`，还是继续停在 review

## 判断边界

### 什么时候不要误判成“水”

- 这章虽然慢，但局面确实变了
- 爽点不大，但风险、关系或信息发生了可感知变化
- 这是卷中必要缓冲段，且明确为后续兑现服务

### 什么时候一定要判为高风险

- 连续多章都没有明确变化
- 章末一直埋，下一章一直不接
- 角色一直忙，但卷目标没有被推进
- 爽点、升级、关系、风险四条线一起停滞

## 和其他 skill 的关系

- 单章推进链设计：`scene-drive`
- 句法 / AI 味 / 对白审稿：`style-audit`
- 开头 / 黄金三章审稿：`opening-review`
- 整稿商业化诊断与总览分流：`editorial-review`
- 真正改稿：`chapter-execution`

默认关系是：

- `pacing-audit` 负责指出哪一段开始发虚、为什么发虚
- `scene-drive` 负责把失衡的推进链重新搭对
- `chapter-execution` 负责真正落稿
- `character-arc` 负责角色弧线诊断
- `skill-evolution` 负责记录反馈、沉淀偏好

> 💡 如果用户对节奏建议不认同，可以提示：
> "要不要让 skill-evolution 记录一下这次的反馈？"
