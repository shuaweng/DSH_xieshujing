# 写书鲸品牌规范（B5）

## 品牌主张

写书鲸是面向长篇创作的人机协同小说工作台。品牌语气应当沉静、可靠、有文学气质，同时保留一点温和的生命感。

品牌口号：**让故事被好好写完**。

## 品牌定位

- 品类：AI 原生长篇小说工作台。
- 核心价值：把分散的构思、资产、写作和 Agent 协作组织成一条可靠的长篇创作链路。
- 品牌人格：沉静的编辑、可靠的搭档、克制的技术产品。
- 情感利益：让作者感到故事有人接得住，修改有退路，长篇写作不会失控。

写书鲸不是可爱吉祥物软件，也不是用聊天替代创作的 AI 玩具。主视觉的生命感只用来降低工具的冰冷感，专业与可靠始终优先。

## 核心标识

B5 是唯一主品牌表情：小圆眼、极短微笑。鲸尾与钢笔笔尖合为一个结构，腹部延伸成连续书写线，表达“写作工具”和“长篇陪伴”。

- 横向 PNG 品牌标志用于首页、启动页和正式传播物料。
- 透明 PNG 独立鲸鱼标志用于工作台入口、工具栏、头像和水印。
- PNG 应用图标使用深墨蓝底与暖纸色反白标志。
- 24 px 以下使用简化小图标；可隐藏微笑，但不能改变鲸鱼和笔尖结构。

## 品牌色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 墨海蓝 | `#24313B` | 主标志、标题、主要操作 |
| 雾霭蓝 | `#748DA0` | 次级信息、链接、选中状态 |
| 浅蓝灰 | `#AEBCC6` | 分割线、禁用态、弱背景 |
| 暖纸白 | `#F6F1E8` | 页面背景、反白标志 |
| 炭墨黑 | `#2D2B28` | 正文文本 |
| 朱砂红 | `#B5634B` | 少量强调、警示和批注 |

朱砂红只用于少量重要信息，不作为大面积装饰色。界面主题应以墨海蓝、暖纸白和雾霭蓝为主。

## 字体

- 中文标题和品牌名：思源宋体 CN / Source Han Serif SC，Bold 或 Heavy。
- 中文正文：思源宋体 CN Regular；交互控件可使用苹方。
- 英文和数字：Inter。
- 标题字重与正文形成明显层级，但不使用夸张字距和艺术字体。

## 语言风格

产品文案使用短句、主动语态和写作现场的词汇。避免空泛鼓励、技术术语和过度拟人。

推荐：

- “欢迎回来，继续写个好故事吧。”
- “先把这场戏的三种走向摆出来。”
- “这份修改基于第一章当前版本。”
- “正文已经变化，请重新审阅这份提案。”

避免：

- “伟大的创作旅程即将开启！”
- “您的 AI 小鲸鱼正在努力思考中……”
- “一键赋能小说内容生产。”

Agent 的语气应像可信赖的编辑：先给判断，再给理由；提出问题但不迎合；未经授权不声称已经修改正文。

## 产品视觉应用

- 首页：暖纸白大面积留白，主标志只出现一次，鲸鱼水印保持低对比度。
- 写作页：正文是视觉中心，品牌色服务于导航、选中、引用和 Diff，不抢正文注意力。
- Agent 区：使用墨海蓝表示可执行能力，雾霭蓝表示引用和上下文，朱砂红只表示冲突或高风险问题。
- 封面：默认底图保持克制，为书名和作者名预留大面积空间；用户自定义封面后不叠加品牌鲸鱼。
- 动效：书写线可用于加载和生成进度，单次循环不超过 1.2 秒，不做连续跳动或摇摆。

## 留白与尺寸

- 标志四周至少保留一个“笔尖宽度”的净空。
- 横向标志最小宽度为 140 px。
- 独立标志最小尺寸为 24 px；推荐工具栏尺寸为 28–32 px。
- 应用图标不得在圆角底板外额外添加描边、阴影或第二层边框。

## 表情与动态状态

B5 中性微笑是静态主标识。状态化表情仅用于产品内反馈，不用于对外主品牌：

- 专注：隐藏微笑，眼睛保持小而克制。
- 完成：微笑弧度可略微增加。
- 思考：允许非常轻的呼吸或尾部书写线动画。
- 错误：不做哭脸或夸张表情，使用朱砂红状态提示。

## 禁止用法

- 不放大眼睛、增加腮红、张嘴或做卡通化拟人。
- 不旋转、拉伸、描边或添加立体高光。
- 不把鲸尾和钢笔笔尖拆开。
- 不随意改变主色，或把标志放在对比不足的背景上。
- 不在小尺寸继续保留过细的线条细节。
