# Agent Note：保持书库和初始化画布的视觉连续性

状态：已实现

[English](2026-09-01-continuous-library-canvas.md) | 中文

## 问题

写书鲸书库原先通过页面顶部一个固定宽高比的伪元素绘制品牌背景。当书库内容高度超过这张背景时，图片下边缘会直接暴露，随后出现一块割裂的白色区域。尚未初始化的项目也会保留普通书本的资产侧栏；此时没有资产可供导航，侧栏只会挤压初始化表单并增加无关界面元素。

## 决策

书库的完整滚动区域共用一套背景。暖色纸张蒙层和品牌图片直接成为滚动根节点的背景层，不再是有固定边界的顶部装饰，因此内容变长时不会露出另一块白色区域。

当画布包含项目初始化界面时，工作台网格把资产侧栏轨道收缩为零，并隐藏侧栏及其展开按钮。项目初始化成功以前，品牌背景与初始化表单是小说工作台中唯一显示的内容。

## 考虑过的替代方案

**继续增加原有顶部背景装饰的高度。** 固定高度只能暂时把接缝向下移动；书籍列表继续增长后，同一问题仍会再次出现。

**为了界面一致性保留空资产侧栏。** 初始化以前，侧栏没有有效的导航职责，还会破坏初始化页面的构图，因此已初始化与未初始化项目采用不同的界面元素更合理。

## 结果

书库从首屏到书籍列表末尾保持同一种视觉材质。新项目使用完整的工作台画布，不再展示空资产导航；已经初始化的项目继续保留原有的可折叠资产侧栏。
